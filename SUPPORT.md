# Getting help

| You want to…                                            | Go to                                                                                                     |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Learn how to use the app or build a plugin              | [Docs](https://harness.novadiffusion.com/en/docs) (中文: [/docs](https://harness.novadiffusion.com/docs)) |
| Ask a question, share an idea                           | [GitHub Discussions](https://github.com/pkuinfo/pku-harness/discussions)                                  |
| Report a broken page, docs error or marketplace problem | [Website issues](https://github.com/pkuinfo/pkuharness-website/issues/new/choose)                         |
| List your plugin in the marketplace                     | [Submit page](https://harness.novadiffusion.com/en/marketplace/submit)                                    |
| Report an app bug                                       | [App issues](https://github.com/pkuinfo/pku-harness/issues/new/choose)                                    |
| Report a broken campus service or request a new one     | [Plugin issues](https://github.com/pkuinfo/pku-harness-plugins/issues/new/choose)                         |
| Report a security vulnerability                         | Privately, as described in [SECURITY.md](SECURITY.md)                                                     |

Never post passwords, tokens, student IDs or other personal data. PKU Harness is maintained by
student volunteers and is not an official Peking University product.
