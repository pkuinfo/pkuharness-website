[插件市场](/marketplace)收录了所有 PKU Harness 插件：官方插件，以及社区插件。社区插件要么是一个带 `PLUGIN.md` 的文件夹（由 App 解释执行），要么是远程 MCP 服务器。和 [skills.sh](https://skills.sh) 一样，插件市场**从 GitHub 仓库建立索引**：你不用上传安装包，只要把一个公开仓库告诉插件市场，它就会找出里面的所有插件。

## 上架流程 [#how-listing-works]

<Steps>
<Step>

**为每个插件写一个 `PLUGIN.md`。** 一个插件一个文件夹，放在哪一层都行。YAML frontmatter 声明插件是什么、能碰哪些东西；Markdown 正文告诉助手怎么用它；工具放在 `tools/*.yaml` 里。一个仓库可以放一个插件，也可以放一百个。详见[清单参考](/docs/marketplace/manifest)。（在 `PLUGIN.md` 的 `remote.mcp` 取代它之前，远程 MCP 服务器仍然可以用 `pku-harness.plugin.json` 来描述。）

</Step>
<Step>

**检查并提交仓库。** 把仓库粘贴到 [/marketplace/submit](/marketplace/submit)。网站会实时扫描，列出找到的每个插件，以及它们的错误、警告和卡片预览。点**提交上架**会打开一个预填好的 GitHub issue；机器人再扫描一遍，开一个把仓库加进 `data/sources.json` 的 pull request，由维护者合并。

</Step>
<Step>

**推送即更新。** 插件市场大约每小时重新扫描一次所有已上架的仓库。改清单、加插件文件夹或删掉一个，列表都会跟着变，不需要重新提交。

</Step>
</Steps>

## 标识与 id [#handles-and-ids]

插件的**标识**（handle）是 `owner/repo/path`，即存放 `PLUGIN.md` 的文件夹，比如 `alice/campus-tools/canteen`。它在本站的页面地址用的则是 id：`/marketplace/alice/campus-tools/canteen-menu`。`id` 必须**在整个插件市场里唯一**，因为 App 把工具注册为 `<id>.<tool>`（远程插件则注册为 MCP 服务器 `mcp-<id>`），id 重复的两个插件会在手机上冲突。先上架的仓库保留这个 id，官方 id 是保留字。

## 官方、已审核与社区 [#official-verified-and-community]

| 徽章 | 含义 |
|---|---|
| **官方 Official** | 由 pkuinfo 在 [`pku-harness-plugins`](https://github.com/pkuinfo/pku-harness-plugins) 里维护，从其中的 `registry/registry.json` 上架。 |
| **已审核 Verified** | 维护者读过源码的社区插件。按插件 id 记录在 `data/sources.json` 里。 |
| **社区 Community** | 通过扫描器检查后自动上架，还没有人读过源码。 |

未审核的插件用起来完全一样。徽章只是告诉同学这个插件经过了多少审查。什么样的插件会被审核通过或下架，见[审核规则](/docs/marketplace/review)。

## App 如何安装插件 [#how-the-app-installs-a-plugin]

- **声明式**插件（`PLUGIN.md`）**通过链接**安装。插件页上有*在 App 中打开*按钮（`pkuharness://plugin?src=…`）、二维码，以及可以粘贴到「设置 → 插件」里的安装链接（GitHub 文件夹 URL）。App 拉取文件，弹出审查面板（官方还是社区、用到的校园服务、网站、App 功能，以及每个工具的效果），然后把插件存到手机上。之后 App 会定期重新拉取链接：没有新增权限的更新静默生效，要求更多权限的更新会等用户确认。
- **内置**插件随 App 一起提供，用户在「设置 → 插件」里开启。其中的官方插件文档和其他文档一样，从各自的 GitHub 链接更新。
- **远程**插件是 MCP 服务器（Streamable HTTP）。用户可以在「设置 → 插件 → 插件市场」里添加，也可以手动粘贴端点 URL。App 连接端点，把它的工具注册为 `mcp-<id>`。如果是 `"auth": "bearer"`，用户需要粘贴一个 token，它只保存在手机的钥匙串里。
- **自建**插件（没有 `endpoint`）会连同源码一起列出。用户自己部署一个实例，再粘贴它的 URL。

手机上不运行任何第三方代码：App 解释执行 `PLUGIN.md` 里声明的步骤，远程插件则跑在作者自己的服务器上。校园请求由 App 带着用户的会话发出，插件永远看不到密码、cookie 或 token。

## 给 App 和 AI Agent 用的接口 [#for-the-app-and-for-agents]

| URL | 内容 |
|---|---|
| [`/marketplace.json`](/marketplace.json) | 完整索引（`MarketplaceIndex`：`plugins[]` + `sources[]`），支持 CORS，每小时刷新。 |
| [`/marketplace/llms.txt`](/marketplace/llms.txt) | 同一份列表的 Markdown 版，给语言模型读。 |
| [`/schema/plugin-manifest.v1.json`](/schema/plugin-manifest.v1.json) | `pku-harness.plugin.json` 的 JSON Schema（远程 MCP 的兼容方案）。 |
| `POST /api/marketplace/scan` | `{ "repo": "owner/repo" }` → 扫描报告（有频率限制；提交页用的就是它）。 |
