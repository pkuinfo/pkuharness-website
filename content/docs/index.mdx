PKU Harness is one app a PKU student installs, signs in to once with their campus account (IAAA),
and then uses to reach every campus system: timetable, campus card, network fee, Treehole (树洞),
Blackboard (教学网), finance, room booking, and anything a plugin adds. An AI agent sits at the
core and acts through those systems for the student, while the same capabilities stay one tap
away in native UI.

## Everything is a plugin

The app is only a **harness**: an agent loop, a design system and a set of host services. Every
capability (each campus service, the dashboard, reminders, the model provider) is a **plugin**, and
every plugin is equal. A plugin that ships inside the app and one that a student runs on their own
server use the same contract, show up in the same plugin list, and are governed by the same
permissions.

```
 ┌──────────────── PKU Harness app (the harness) ────────────────┐
 │  Agent loop      Design system (HostUI)     Host services      │
 │      │                  │                 (campus, scheduler,  │
 │      └────── tools ─────┴───── screens ──  widgets, todos, …)  │
 └──────────▲──────────────────────▲──────────────────▲───────────┘
            │                      │                  │
   bundled plugins          remote plugins       PKU Harness Cloud
   (TypeScript, SDK)        (MCP over HTTPS)     (optional backend)
```

Two rules follow from this, and they shape everything in these docs:

- **Human and AI are equal operators.** Every capability is one typed tool. A screen calls it when
  the user taps; the agent calls it in a conversation. Anything the user can do, the agent can do,
  and the other way round.
- **Credentials never leave the device.** The harness signs in to campus services itself and hands
  plugins responses, never passwords or session tokens.

## Feeding these docs to an agent

Every page is also available as Markdown, so you can give an agent exactly the context it needs.

| URL | Content |
| --- | --- |
| [`/llms.txt`](/llms.txt) | Index of every page with its one-line description |
| [`/llms-full.txt`](/llms-full.txt) | Every page in one file |
| `/docs/<page>.md` | One page, e.g. [`/docs/sdk/plugin.md`](/docs/sdk/plugin.md) |
| `/docs/<page>` with `Accept: text/markdown` | Same as `.md` (content negotiation) |

Each page also has **Copy Markdown** and **Open in…** buttons under its title. The Cloud API
reference pages render their operations and schemas as text in the Markdown version.

```bash
# Give Claude Code the plugin checklist and the SDK contract
curl -s https://<this-site>/docs/for-agents.md https://<this-site>/docs/sdk/plugin.md > plugin-context.md
```
