`@pku-harness/cloud-protocol` is pure TypeScript that runs on Hermes, Bun and in browsers. The
app, the reference server and viewer pages import the same code, so the wire format and the
encryption can't drift apart. Dependencies: `@noble/ciphers`, `@noble/curves` and `@noble/hashes`
(pinned), with `zod ^4` as a peer. Plugins normally don't import it, because the host does the
cloud work for them. Servers and viewer pages do.

It lives in `packages/cloud-protocol` of
[`pku-harness-plugins`](https://github.com/pkuinfo/pku-harness-plugins) and isn't published to
npm. Use it from a checkout (workspace package `@pku-harness/cloud-protocol`), or copy the `src/`
folder into your server or page build.

Wire conventions: binary data is base64url without padding, times are Unix ms unless the name
ends in `S` (seconds), and parsing strips unknown keys.

## Viewer page: join a channel and decrypt

```ts
import {
  deriveShareKeys,
  envelopeSchema,
  fromB64url,
  generateBoxKeyPair,
  joinResponse,
  open,
  parseKeyFragment,
  paths,
  peerInFrame,
  channelInfoResponse,
  toB64url,
  viewerPeerKey,
} from '@pku-harness/cloud-protocol';

// after GET /s/<id> the page is at /w/<plugin>/<page>?c=<id>#k=<secret>
const channelId = new URLSearchParams(location.search).get('c')!;
const k = parseKeyFragment(location.hash);
if (!k) throw new Error('link has no key');
const { authKey, encKey } = deriveShareKeys(k);

const info = channelInfoResponse.parse(await (await fetch(paths.publicChannel(channelId))).json());
const meta = open(encKey, info.meta);          // the owner's sealed meta (validate it!)

const me = generateBoxKeyPair();
const joined = joinResponse.parse(
  await (
    await fetch(paths.join(channelId), {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ authKey: toB64url(authKey), peerPub: toB64url(me.publicKey) }),
    })
  ).json(),
);

const key = viewerPeerKey(me.secretKey, me.publicKey, fromB64url(info.chanPub), encKey);
const ws = new WebSocket(new URL(paths.peerWs(channelId, joined.peerToken), location.href).href.replace(/^http/, 'ws'));
ws.onmessage = (ev) => {
  const frame = peerInFrame.parse(JSON.parse(ev.data));
  if (frame.t === 'msg') console.log(open(key, envelopeSchema.parse(frame.env)));
};
```

The reference server redirects `/s/<id>` to `/w/<plugin>/<page>?c=<id>`. The browser carries
the `#k=` fragment across the redirect by itself, and the server never sees it. Webviews without
WebSocket use `GET /v1/c/{id}/events?t=` (SSE) and `POST /v1/c/{id}/send` instead. For a complete
viewer, see `plugins/card-share/web` (a port of pkubdcard's UI).

## Server: verify a token request

```ts
import { authTokenRequest, fromB64url, verifyAuthChallenge } from '@pku-harness/cloud-protocol';

const body = authTokenRequest.parse(await req.json());
const device = await db.device(body.deviceId);           // stored signPub
const check = verifyAuthChallenge(body, fromB64url(device.signPub), { aud: 'https://cloud.example.org' });
if (!check.ok) return error(401, 'unauthorized', check.reason);
if (await nonces.seen(body.nonce)) return error(401, 'unauthorized', 'replay');
// issue a token with claims { sub: deviceId, plg: plugin, svc: services, iat, exp: iat + 600_000 }
```

The [API reference](/en/docs/cloud/api/meta) lists every endpoint.
