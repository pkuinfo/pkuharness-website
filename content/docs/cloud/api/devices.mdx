      - content: >
          Registers a device identity. Authenticated by proof of work instead of
          a token: find a

          decimal `nonce` such that `SHA-256(prefix ‖ UTF-8(nonce))` starts with
          at least

          `pow.difficulty` zero bits (from `GET /v1/meta`), where


          ```

          prefix = UTF-8("pku-harness-cloud/v1/pow\n" + salt + "\n" + signPub +
          "\n" + boxPub + "\n")

          ```


          The server accepts its current salt and the previous one. Binding the
          keys into the prefix

          means one solution registers exactly one identity. Clients refuse a
          difficulty above 28

          (`MAX_POW_DIFFICULTY`); the default is 16 (about one second on a
          phone). Use `solvePow` from

          `@pku-harness/cloud-protocol`.
        heading: register-a-device
      - content: >
          Exchanges an Ed25519-signed challenge for a 10-minute bearer token
          bound to one device, one

          plugin and a set of services (claims `sub = deviceId`, `plg = plugin`,
          `svc = services`).

          The signed bytes are these lines joined by `\n` (no trailing newline):


          ```

          pku-harness-cloud/v1/auth

          <aud>        provider origin, lowercase scheme://host[:port], no path

          <deviceId>

          <plugin>

          <services>   deduplicated, sorted, joined by ","

          <ts>         Unix ms, decimal

          <nonce>      16 random bytes, base64url

          ```


          The server compares `aud` with its own origin, accepts `|now − ts| ≤ 5
          min` and rejects a

          reused nonce within that window. Use `signAuthChallenge` from

          `@pku-harness/cloud-protocol`.
        heading: mint-a-plugin-token

          plugin token of the device works. The app calls it from Settings →
          删除云端数据 and before a full reset.
