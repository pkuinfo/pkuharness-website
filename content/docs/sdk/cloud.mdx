源码：`packages/sdk/src/cloud.ts`。指南：[云服务 → 插件指南](/docs/cloud/plugin-guide)。线上协议：
[`@pku-harness/cloud-protocol`](/docs/cloud/protocol-package) 和 [API 参考](/docs/cloud/api/meta)。

插件在 `PluginDef.cloud` 里声明要用的服务，拿到一个绑定到自身的客户端（`ctx.cloud`、`props.cloud`）。设备身份、token 和密钥都由宿主保管；宿主负责执行用户的授权和插件清单，并和用户选定的服务商通信（官方、自建服务器或任意 URL）。插件看不到 token、密钥和服务商凭据，助手也看不到分享链接。

<Callout title="宿主支持情况">
  应用已经实现了这个客户端。为了兼容不支持云服务的宿主，`ctx.cloud` 的类型仍是可选的（`PluginCloud | undefined`），使用前先检查 `ctx.cloud?.available`。`push` 暂未提供，调用会以 `not_configured` 失败。官方服务器关闭了服务端函数，只运行中继和一个小型加密存储；而且服务端函数要以明文读取输入，所以 `e2e` 插件调用 `functions.invoke` 会被宿主拒绝。能在手机上做的事就放在手机上，确实需要服务器的话请用你自己的后端。
</Callout>

## CloudManifest [#cloudmanifest]

```ts
type CloudService = 'store' | 'channels' | 'push' | 'files' | 'functions';

interface CloudManifest {
  protocol: 1;
  uses: CloudService[];
  /** Plain-language lines shown in the consent sheet: exactly what leaves the device. */
  disclosure: { zh: string[]; en?: string[] };
  /** All store/channel payloads are client-encrypted; the host refuses plaintext writes when true. */
  e2e: boolean;
  /** Plugin still works without cloud; features check ctx.cloud.available. Else requires 'cloud'. */
  optional?: boolean;
  /** Server functions: run on the user's provider (code in plugins/<id>/server) or an external URL. */
  functions?: Record<string, CloudFunctionDecl>;
  backend?: { kind: 'provider' } | { kind: 'external'; url: string };
  /** Static pages from plugins/<id>/web served at /w/<plugin>/<page> (viewers without the app). */
  pages?: string[];
}

interface CloudFunctionDecl<I extends z.ZodType = z.ZodType, O extends z.ZodType = z.ZodType> {
  title: string;
  input: I;
  output: O;
  version: number;
  timeoutMs?: number;
}

function defineCloudFunction<I extends z.ZodType, O extends z.ZodType>(d: CloudFunctionDecl<I, O>): CloudFunctionDecl<I, O>;
```

## PluginCloud [#plugincloud]

```ts
interface PluginCloud {
  /** Provider configured, consent given and reachable (offline-tolerant reads aside). */
  readonly available: boolean;
  status(): CloudStatus;
  /**
   * Ask the user to allow this plugin to use the cloud (the host's consent sheet; resolves at once
   * when already allowed). False when they decline. Screens call it before opening a channel;
   * agent tool calls never prompt and get `CloudError('consent_required')` instead.
   */
  requestConsent(): Promise<boolean>;
  /** Key-value store namespaced to (device, plugin) by the provider. Values are sealed when `e2e`. */
  store: {
    get<T>(key: string): Promise<{ value: T; version: number } | undefined>;
    put<T>(key: string, value: T, opts?: { ifVersion?: number; ttlS?: number }): Promise<{ version: number }>;
    delete(key: string): Promise<void>;
    list(prefix?: string): Promise<{ key: string; version: number; updatedAt: number }[]>;
  };
  /** End-to-end encrypted relay channels (live sharing with people who open a link). */
  channels: {
    /** `meta` is sealed with the link key; viewers read it before joining. */
    open(opts: { ttlS: number; maxPeers?: number; page?: string; meta?: unknown }): Promise<Channel>;
    /** Survives app restarts (keys are kept in secure storage). */
    get(id: string): Channel | undefined;
    list(): Channel[];
  };
  /** Stage 6. */
  push: {
    schedule(at: number, payload: unknown): Promise<string>;
    cancel(id: string): Promise<void>;
  };
  /** Server functions declared in `CloudManifest.functions` (stage 6). */
  functions: {
    invoke<N extends string>(name: N, input: unknown, opts?: { signal?: AbortSignal }): Promise<unknown>;
  };
}

interface CloudStatus {
  provider: 'official' | 'custom' | 'off';
  baseURL?: string;
  /** The user allowed this plugin to use the cloud. */
  consented: boolean;
  online: boolean;
}
```

## Channel [#channel]

```ts
interface Channel {
  id: string;
  expiresAt: number;
  link: SecretLink;
  peers(): { id: string; joinedAt: number }[];
  /** Subscribe; returns an unsubscribe function. */
  on(ev: ChannelEventType, fn: (e: ChannelEvent) => void): () => void;
  /** Sealed per peer; '*' = every connected peer. */
  send(peerId: string | '*', msg: unknown): Promise<void>;
  /** Sealed blobs readable by peers while the owner is offline (batch mode). */
  mailbox: {
    put(slot: string, msg: unknown, ttlS: number): Promise<void>;
    clear(): Promise<void>;
  };
  /** Drop a peer and free its seat (a new viewer can join with the same link). */
  kick(peerId: string): Promise<void>;
  extend(ttlS: number): Promise<void>;
  close(): Promise<void>;
}

type ChannelEventType = 'join' | 'leave' | 'message' | 'closed';
type ChannelCloseReason = 'owner' | 'expired' | 'revoked' | 'locked' | 'server';

type ChannelEvent =
  | { type: 'join'; peerId: string; at: number }
  | { type: 'leave'; peerId: string; at: number }
  /** A peer's frame, already decrypted (validate it with zod before use). */
  | { type: 'message'; peerId: string; msg: unknown }
  | { type: 'closed'; reason: ChannelCloseReason };
```

## SecretLink [#secretlink]

```ts
/**
 * An opaque share link (`https://<provider>/s/<id>#k=…`). Plugins can't read the URL: show it with
 * `host.shareLink(link)` or `<QRCode link={link} />`. `JSON.stringify(link)` gives "[secret link]".
 */
interface SecretLink {
  readonly kind: 'secret-link';
  readonly channelId: string;
  toJSON(): string;
}
```

宿主的 `toString` 同样输出 `"[secret link]"`，所以链接不会混进工具结果或日志。

## 错误 [#errors]

```ts
type CloudErrorCode = 'not_configured' | 'consent_required' | 'offline' | 'rate_limited' | 'quota' | 'gone' | 'protocol' | 'server';
const CLOUD_ERROR_CODES: readonly CloudErrorCode[];

class CloudError extends Error {
  readonly code: CloudErrorCode;
  /** Set for 'rate_limited' (from Retry-After). */
  readonly retryAfterS?: number;
  constructor(code: CloudErrorCode, message: string, retryAfterS?: number);
}

function isCloudError(e: unknown, code?: CloudErrorCode): e is CloudError;
```

| 错误码 | 含义 |
| --- | --- |
| `not_configured` | 没有配置服务商，或该服务不可用（比如 `push`） |
| `consent_required` | 用户还没允许这个插件使用云服务 |
| `offline` | 没有网络。写入和函数调用会立即失败，不会悄悄排队重发 |
| `rate_limited` | 服务商返回 429，`retryAfterS` 有值 |
| `quota` | 超出存储或通道配额 |
| `gone` | 通道已关闭或已过期 |
| `protocol` | 服务商的响应不符合协议 v1，或调用违反了清单（使用未声明的服务、`e2e` 插件发送明文） |
| `server` | 服务商的其他错误 |
