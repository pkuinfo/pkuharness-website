内置插件只依赖我们的 `@pku-harness/sdk`，其余引入的只有 `zod`、`react` 和 `react-native`。SDK 以
TypeScript 源码的形式放在插件仓库里，由 App 的打包器（Metro）和 App 代码一起编译。对等依赖：
`zod ^4`、`react >=19`。

## 安装 [#install]

SDK 没有发布到 npm。它在
[`pku-harness-plugins`](https://github.com/pkuinfo/pku-harness-plugins) 仓库的 `packages/sdk`
目录下，开发时直接在这个仓库的检出里工作：仓库的 bun workspace 和 `tsconfig.json` 会把
`@pku-harness/sdk` 解析到 `packages/sdk/src`。

```bash
git clone https://github.com/pkuinfo/pku-harness-plugins.git
cd pku-harness-plugins
bun install
```

App 把同一个仓库作为 git 子模块挂在 `plugins/`，所以你在这里写的插件也能直接在 App 里运行（见
[内置插件 → 在 App 中运行](/docs/build/bundled-plugin#run-it-in-the-app)）。

```ts
import { definePlugin, defineTool, type PluginScreenProps } from '@pku-harness/sdk';
```

所有内容都从包的根入口导出。插件语言的各个模块也可以单独通过 `@pku-harness/sdk/lang/<module>` 引入。

## 约定 [#conventions]

- 时间一律用 **epoch 毫秒**，需要当作钟点理解时按设备本地时区解释。给模型或表单看的字符串用本地时间
  `"YYYY-MM-DD HH:mm"`。
- 课表的星期沿用 JavaScript 的编号（0 = 周日 … 6 = 周六），但 `weekdayName` 接收的是 1 = 周一 … 7 = 周日。
- Schema 都是 zod 4 对象，类型由 `z.infer` 推出。
- 纯函数工具不引入任何 React Native 模块，用 `bun test` 做单元测试。
