Source: `packages/sdk/src/pointer.ts`.

```ts
/** Minimal JSON-pointer write ("/a/b") used to place binding results into widget state. */
function setPointer(target: Record<string, unknown>, pointer: string, value: unknown): Record<string, unknown>;
```

- Returns a new object; `target` is not mutated (objects along the path are copied).
- Missing or non-object intermediate values become `{}`.
- `~1` decodes to `/` and `~0` to `~` in keys.
- An empty pointer (`""`) returns `target` unchanged.

```ts
setPointer({ form: { amount: '50' } }, '/card/balance', 12.5);
// → { form: { amount: '50' }, card: { balance: 12.5 } }
```
