`@pku-harness/sdk` is the package you use to write a bundled plugin. It defines the object a plugin
exports and the interfaces the host gives to plugins, and it includes a set of pure helper
functions. This section lists its types and functions module by module, for you to look up while
you write a plugin.

A bundled plugin depends on `@pku-harness/sdk` and nothing else from us. Its only other imports are
`zod`, `react` and `react-native`. The SDK ships as TypeScript source in the plugins repository, and
the app's bundler, Metro, compiles it together with the app code. Its peer dependencies are
`zod ^4` and `react >=19`.

## Install

There is no npm package. The SDK lives in
[`pku-harness-plugins`](https://github.com/pkuinfo/pku-harness-plugins) under `packages/sdk`, and
you work inside a checkout of that repository. Its bun workspace and `tsconfig.json` resolve
`@pku-harness/sdk` to `packages/sdk/src`.

```bash
git clone https://github.com/pkuinfo/pku-harness-plugins.git
cd pku-harness-plugins
bun install
```

The app pulls in the same repository as its git submodule `plugins/`, so a plugin you build there
also runs in the app (see [Bundled plugin → Run it in the app](/en/docs/build/bundled-plugin#run-it-in-the-app)).

```ts
import { definePlugin, defineTool, type PluginScreenProps } from '@pku-harness/sdk';
```

Everything can be imported from the package root. You can also import the plugin language modules
one at a time as `@pku-harness/sdk/lang/<module>`.

## Conventions

All SDK modules follow these conventions.

- Times are **epoch milliseconds** (milliseconds since 1 January 1970 UTC). Where a time is read as
  a clock time, it is read in the device's local time zone. Strings that the model or a form sees
  use the local format `"YYYY-MM-DD HH:mm"`.
- Timetable weekdays use JavaScript numbering (0 = Sunday … 6 = Saturday), but `weekdayName` takes
  1 = Monday … 7 = Sunday.
- Schemas are zod 4 objects. The matching TypeScript types are derived from them with `z.infer`.
- Pure helpers import nothing from React Native, so they can be unit-tested directly with
  `bun test`.
