Source: `packages/sdk/src/plugin.ts`. Concepts: [Host services](/en/docs/concepts/host-services).

```ts
interface HostServices {
  browser: {
    open(url: string): Promise<{ opened: true }>;
  };
  files: {
    pick(opts?: { types?: string[]; multiple?: boolean }): Promise<PickedFile[]>;
  };
  crypto: {
    sha256(text: string): Promise<string>;
  };
  registry: {
    plugins(): PluginInfo[];
    tool(id: string): ToolInfo | undefined;
  };
  docs?: {
    review(input: { link?: string; files?: Record<string, string> }): Promise<{ opened: true }>;
    source(id: string): { link: string | null; version: string; files: Record<string, string> } | null;
  };
  remote: {
    install(input: { url: string; name?: string; token?: string }): Promise<{ id: string; name: string; tools: { name: string; effect: ToolEffect }[] }>;
    uninstall(id: string): Promise<void>;
    has(id: string): boolean;
  };
  genui: {
    describeCatalog(): string;
    checkSpec(spec: unknown): SpecCheck;
  };
  notify: {
    readiness(): Promise<NotifyReadiness>;
    fix(kind: NotifyFixKind): Promise<NotifyReadiness>;
  };
  sms: {
    awaitCode(): Promise<string | null>;
  };
  scheduler: {
    create(input: JobInput): Promise<Job>;
    update(id: string, patch: JobPatch): Promise<Job>;
    remove(id: string): Promise<void>;
    get(id: string): Job | undefined;
    list(): Job[];
    runCheck(id: string): Promise<CheckResult>;
  };
  widgets: {
    list(): Widget[];
    get(id: string): Widget | undefined;
    newId(): string;
    put(widget: Widget): Promise<void>;
    remove(id: string): Promise<void>;
    reorder(ids: string[]): Promise<void>;
    preview(widget: Widget): Promise<Record<string, unknown>>;
    resolve(widget: Widget, force?: boolean): Promise<Record<string, unknown>>;
    catalog(): WidgetCatalogEntry[];
  };
  todos: {
    list(): Todo[];
    get(id: string): Todo | undefined;
    add(input: TodoInput, source: JobSource): Promise<Todo>;
    update(id: string, patch: Partial<TodoInput>, source: JobSource): Promise<Todo>;
    setDone(id: string, done: boolean): Promise<Todo>;
    remove(id: string): Promise<void>;
  };
  campus: {
    status(): CampusStatus;
    request(service: CampusService, req: CampusRequest): Promise<CampusResponse>;
    otp(): Promise<OtpCode | null>;
    otpStatus(): Promise<OtpStatus>;
    otpBindStart(): Promise<{ sentTo: string | null }>;
    otpBindFinish(smsCode: string): Promise<OtpStatus>;
    otpUnbindLocal(): Promise<void>;
    openSignedIn(service: CampusService): Promise<{ opened: true }>;
  };
  ongoing?: {
    start(opts: OngoingOptions): OngoingHandle;
  };

    get(): { courses: Course[]; semester: Semester | null; reminderMinutes: number | null };

    setReminderMinutes(minutes: number | null): Promise<void>;
    reloadSemester(): Promise<void>;
  };
}
```

## Behaviour notes

| Member | Notes |
| --- | --- |
| `browser.open` | Opens the page in the system browser tab (Custom Tabs / SFSafariViewController). App links on that page (`weixin://`, `alipays://`) open those apps, so a checkout can end in WeChat Pay or Alipay. Resolves as soon as the page is open and can't tell whether a payment went through: re-read the result (a balance, say) when the user comes back. |
| `files.pick` | Only the user picks files. Call it from a screen in response to a tap, never from an agent tool. `types` are MIME types and may use wildcards (`['application/pdf', 'image/*']`). Resolves `[]` on cancel. The files are copied into the app cache and you get references (URIs valid for this app session), not bytes. |
| `crypto.sha256` | SHA-256 of the UTF-8 text as lowercase hex. Meant for request signatures, since plugins have no crypto of their own. |
| `registry` | Read-only view of installed plugins and tools. `tool(id)` also resolves legacy ids. |
| `docs` | Document (`PLUGIN.md`) plugins, used by the `plugins` plugin. `review` opens the app's permission sheet for a link or a set of files and resolves once the sheet is shown; the user decides there. `source(id)` returns an installed document plugin's files (to read or fork it), or `null` for any other plugin. Optional: check before use. |
| `remote` | Installs and removes remote MCP plugins. Used by the `plugins` plugin. |
| `genui` | `describeCatalog()` returns the component catalog as text you can put in a tool description. `checkSpec(spec)` validates a spec against it. |
| `notify.readiness` / `fix` | Tells you whether reminders can fire on the minute (notification permission, exact alarms, battery optimisation). Call `fix` only from a tap. System screens may return before the user changes anything, so read readiness again when the app comes back to the foreground. |
| `sms.awaitCode` | Resolves with the code from the next incoming SMS once the user allows reading that one message (Android SMS User Consent). Gives `null` when unavailable, denied, unclear or after 5 minutes. Call it right after you ask the service to send the SMS. |
| `scheduler` | `Trigger`, `Action` and `Job` are on the [scheduler](/en/docs/sdk/scheduler) page. `runCheck` runs a check job immediately. |
| `widgets.preview` / `resolve` | Fill in a widget's bindings and return the state its spec will see. `preview` always fetches; `resolve` goes through the TTL cache unless `force` is set. |
| `widgets.catalog` | Native widgets contributed by enabled plugins. |
| `todos` | `source` records who made the change. |
| `campus.request` | Needs the `campus-session` capability. See [campus](/en/docs/sdk/campus). |
| `campus.otp` | The current 手机令牌 code if the user bound the app's authenticator, otherwise `null`. You never get the secret. |
| `campus.otpStatus`, `otpBindStart`, `otpBindFinish`, `otpUnbindLocal` | Authenticator management. Only the bundled authenticator plugin's screens should call these. |
| `campus.openSignedIn` | Opens the service in the system browser, already signed in through the service's own hand-off. The host builds the URL, so the plugin never sees the session token. Rejects if the service has no hand-off. |
| `ongoing` | Exists only with the `ongoing` capability (Android). Start it from a user action and stop it when you're done. |
| `timetable.reloadSemester` | Re-reads the semester after the calendar plugin has saved it. |

## Types used above

```ts
type JobInput = { title: string; trigger: Trigger; action: Action; source: JobSource; enabled?: boolean; meta?: Record<string, unknown> };
type JobPatch = Partial<Pick<Job, 'title' | 'trigger' | 'action' | 'enabled' | 'meta'>>;
type CheckResult = { notified: boolean; value?: unknown; error?: string };

type ToolInfo = { id: string; pluginId: string; title: string; effect: ToolEffect };

type PluginInfo = {
  id: string;
  name: string;
  kind: 'system' | 'builtin' | 'remote';
  enabled: boolean;
  modes: Record<ToolEffect, 'auto' | 'ask' | 'off'>;
  tools: { id: string; title: string; effect: ToolEffect }[];
};

interface WidgetCatalogEntry {
  plugin: string;
  pluginName: string;
  widget: string;
  title: string;
  description: string;
  sizes: WidgetSize[];
  defaultSize: WidgetSize;
  /** JSON Schema of the widget's config, if it takes any. */
  config?: Record<string, unknown>;
}

interface OngoingOptions {
  title: string;
  body?: string;
  /** When the activity ends (ms epoch): shown as a countdown; the host stops it then. */
  until?: number;
  /** Label of the notification's stop action (default 停止). */
  stopLabel?: string;
  /** Called when the user taps stop (or the system ends the service). */
  onStop?: () => void;
}

interface OngoingHandle {
  update(p: { title?: string; body?: string }): void;
  stop(): void;
}
```

## Example: pick a file and upload it

```ts
import type { HostServices } from '@pku-harness/sdk';

/** Call from a screen's button handler: only the user can pick files. */
export async function pickAndSubmit(services: HostServices, hiddenFields: [string, string][]) {
  const [file] = await services.files.pick({ types: ['application/pdf'] });
  if (!file) return null; // cancelled
  return services.campus.request('blackboard', {
    url: '/webapps/assignment/uploadAssignment?action=submit',
    method: 'POST',
    multipart: {
      fields: hiddenFields, // the submission form's hidden fields (nonce, course_id, content_id…)
      files: [{ field: 'newFile_LocalFile0', name: file.name, mime: file.mime, uri: file.uri }],
    },
  });
}
```

This is a shortened version of what the `courses` plugin does. The real flow (`submitAssignment` in
`plugins/courses/src/api.ts`, ported from pkucli `crates/course`) first reads the submission form to
get its hidden fields and a fresh nonce, then posts, then reads the assignment again to confirm the
attempt. The file bytes never pass through the plugin: the host streams them from the picked URI.
