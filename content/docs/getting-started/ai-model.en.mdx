The agent needs a large language model to work. PKU Harness doesn't run a model service for you,
so you provide your own API key. The key is stored in the phone's keystore, and requests go
directly from your phone to the provider you chose. We may offer a hosted model service later.

Model providers are also supplied by plugins, called _provider plugins_. This means community
plugins can add more providers.

## Providers that ship with the app [#bundled-providers]

The app comes with two provider plugins.

| Provider | Default base URL | Where to get a key |
| --- | --- | --- |
| **DeepSeek** (default) | `https://api.deepseek.com` | Create one under API Keys at [platform.deepseek.com](https://platform.deepseek.com) |
| **OpenAI-compatible** | `https://api.openai.com/v1` (editable) | The provider's API key; leave it empty for a local server |

DeepSeek offers two models.

- `deepseek-flash` is DeepSeek-V4.1-Flash. It has a context of 1M tokens and accepts text and
  images.
- `deepseek-v4-pro` is DeepSeek-V4-Pro. It has a context of 1M tokens.

The OpenAI-compatible provider has no fixed model list. The app reads the list live from the
server's `/models` endpoint.

## Set it up

<Steps>
<Step>

### Open Settings → AI service

You can also do this in the "AI service" step of first-run setup.

</Step>
<Step>

### Pick a provider and paste the key

For an OpenAI-compatible provider, also enter the base URL and pick a model from the list. The
base URL is the path just above `/chat/completions`, which usually ends in `…/v1`.

</Step>
<Step>

### Test the connection

The app sends a small request and shows the result. For DeepSeek it also shows your account
balance.

</Step>
</Steps>

Each conversation can use a different model. To switch, tap the model label above the message
box, or type `/model`.

## Cost and context

The app records how many tokens each request uses. Settings → Usage shows the cache hit rate,
tokens per day, and which models and tools were used. For providers that publish their prices,
such as DeepSeek, it also estimates how much you have spent.

Many providers cache the part at the start of a request that matches an earlier request. This is
called a **prefix cache**, and cached input costs only a small part of the normal price. To hit
the cache as often as possible, the app keeps the start of every request the same. The system
prompt is fixed, the tool list is fixed, and the history only grows at the end without earlier
messages being changed.

When a conversation grows past the context budget, older turns are automatically compacted into
a summary. You set the budget in Settings → AI service → context budget. The default is 128k
tokens.

## Testing without a key

While you develop plugins, you don't need a real model. The plugins repository contains a mock
model that replies from a script. Run it, then point the OpenAI-compatible provider at it.

```bash
# in pku-harness-plugins
bun examples/mock-llm/server.ts
# then in the app: AI service → OpenAI-compatible
#   Base URL: http://10.0.2.2:8788/v1   (emulator; use your machine's LAN IP on a device)
#   Model:    mock-agent
```

[Testing](/en/docs/build/testing) explains what the mock model does.
