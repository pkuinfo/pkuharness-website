The agent needs a language model, and PKU Harness doesn't run one for you. You bring your own key.
It's stored in the device keystore, and requests go straight from your phone to the provider you
picked. A hosted model option may come later.

Model access is a plugin too (a *provider plugin*), so community plugins can add more providers.
Two ship with the app:

| Provider | Default base URL | Models | Key |
| --- | --- | --- | --- |
| **DeepSeek** (default) | `https://api.deepseek.com` | `deepseek-flash` (DeepSeek-V4.1-Flash, 1M context, text + image), `deepseek-v4-pro` (DeepSeek-V4-Pro, 1M context) | Create one under API Keys at [platform.deepseek.com](https://platform.deepseek.com) |
| **OpenAI-compatible** | `https://api.openai.com/v1` (editable) | Listed live from the server's `/models` | The provider's API key; leave empty for a local server |

## Set it up

<Steps>
<Step>

### Open Settings → AI service

Or use the "AI service" step of onboarding.

</Step>
<Step>

### Pick a provider and paste the key

For an OpenAI-compatible provider, also set the base URL and pick a model from the list. The base
URL must end where `/chat/completions` lives, which is usually `…/v1`.

</Step>
<Step>

### Test the connection

The app sends a small request and shows the result. For DeepSeek it also shows your account
balance.

</Step>
</Steps>

You can switch models per chat session with the model pill in the composer, or with `/model`.

## Cost and context

The app records token usage for every request. Settings → Usage shows the cache hit rate, tokens
per day, models and tools, and for providers with published prices (DeepSeek) it estimates what
you've spent.

Requests are built to hit the provider's **prefix cache**: a static system prompt, a fixed tool
block and append-only history. Cached input costs a fraction of uncached input, so this matters.

When a conversation grows past the context budget, older turns are compacted automatically. You
set the budget in Settings → AI service → context budget. The default is 128k tokens.

## Testing without a key

If you're developing, run the scripted mock model from the plugins repository and point the
OpenAI-compatible provider at it:

```bash
# in pku-harness-plugins
bun examples/mock-llm/server.ts
# then in the app: AI service → OpenAI-compatible
#   Base URL: http://10.0.2.2:8788/v1   (emulator; use your machine's LAN IP on a device)
#   Model:    mock-agent
```

[Testing](/en/docs/build/testing) explains what the mock model does.
