PKU Harness 目前支持 **Android**。iOS 版正在准备中。App 已经能在 iOS 上启动，但负责校园网络请求的原生 HTTP 模块还没有移植到 Swift，所以现阶段只能在 Android 上登录校园账号。

## 下载 [#download]

最新的 APK 在[下载页](/download)上。下载页指向 [`pkuinfo/pku-harness`](https://github.com/pkuinfo/pku-harness/releases) 仓库的最新 Release。手机需要是 arm64 架构，系统为 Android 7.0 或更高版本。

安装方式和其他 APK 一样。Android 询问是否允许浏览器安装应用时，选择允许即可。

## 如何确认安装的是官方版本 [#verify-the-build]

每个正式版 APK 都由 GitHub Actions 从打了标签的提交自动构建，并用同一把密钥签名。Release 说明里列出了 APK 和签名证书的指纹。你可以拿它们核对自己安装的文件。

安装之后，JavaScript 代码的修复会通过签名的空中更新（over-the-air update，简称 OTA）推送，下次打开 App 时生效。原生代码的改动仍然需要安装新的 APK。

<Callout type="warn" title="只安装你信任的构建">
  App 会把你的校园账号密码保存在手机的密钥库里。请从官方仓库安装正式版，或者自己从源码构建。
</Callout>

## 首次启动 [#first-run]

第一次打开 App 时，会有一段引导流程，共五步。引导可以中途离开，下次打开时 App 会从你停下的那一步继续。

<Steps>
<Step>

### 同意用户协议 [#accept-the-terms]

同意之后，助手可以直接替你使用插件，不必每次都征求你的同意。之后你可以针对某个插件或某类操作改为先确认，详见[权限](/docs/concepts/permissions)。

</Step>
<Step>

### 接入 AI 模型 [#connect-an-ai-model]

默认使用 DeepSeek。任何兼容 OpenAI 格式的接口也都可以使用。详见[接入模型](/docs/getting-started/ai-model)。

</Step>
<Step>

### 登录校园账号 [#sign-in-with-your-campus-account]

输入学号和密码。App 通过学校的统一身份认证系统 IAAA 验证它们。详见[校园账号](/docs/getting-started/campus-account)。

</Step>
<Step>

### 选择插件 [#pick-plugins]

选择要启用哪些内置插件。之后可以随时在「设置 → 插件」里修改。

</Step>
<Step>

### 允许准时提醒 [#allow-on-time-reminders]

授予通知权限和精确闹钟权限。你也可以让 App 不受电池优化限制。这样，提醒和定时检查才能准时触发。

这一步可以跳过。跳过后，「日程」页会提示还缺少哪些权限。

</Step>
</Steps>

## 四个标签页 [#the-four-tabs]

App 底部有四个标签页。

| 标签页 | 用途 | 提供者 |
| --- | --- | --- |
| **对话** | 和助手交谈 | App 本身 |
| **看板** | 查看余额、课程等关键信息 | `dashboard` 插件 |
| **日程** | 课表、待办和提醒 | `schedule` 插件 |
| **设置** | 账号、插件和各项偏好 | App 本身 |

**对话**页是助手所在的地方。助手的回答会逐字显示出来。它可以调用插件的工具，也可以在对话里直接显示原生界面，例如表单、选择器和卡片。你可以同时开多个会话，用 `/` 开头的快捷指令，也可以发送附件。

**看板**页由一组小组件组成，例如校园卡余额、下一节课和食堂人流。这些小组件由助手按你的要求搭建和修改，并且会自动刷新。

**日程**页显示课表、待办和提醒。提醒的重复规则可以用日常的话描述，例如「每 3 天一次，共 16 次」。

**设置**页包括校园账号、AI 服务、插件及其权限、插件市场、记忆、通知、外观和数据管理。

## 从源码构建 [#build-from-source]

从源码构建需要 JDK 17 和 Android SDK。

```bash
git clone --recurse-submodules https://github.com/pkuinfo/pku-harness.git   # plugins/ 是一个子模块
cd pku-harness
bun install
bun run android        # 在模拟器或真机上运行开发版
```

完整的工具链说明见 App 仓库的 `README.md` 和 `AGENTS.md`。如果想在自己的构建上开发插件，请看[内置插件 → 在 App 中运行](/docs/build/bundled-plugin#run-it-in-the-app)。
