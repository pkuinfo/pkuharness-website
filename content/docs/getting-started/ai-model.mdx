助手需要一个大语言模型，但 PKU Harness 不替你运行模型服务。你自己提供 API 密钥，它保存在设备密钥库里，请求从你的手机直接发给你选的模型服务商。以后可能会提供托管的模型服务。

接入模型本身也是一个插件（叫作“模型服务商插件”，provider plugin），所以社区插件也可以加入更多服务商。App 自带两个：

| 服务商 | 默认 Base URL | 模型 | 密钥 |
| --- | --- | --- | --- |
| **DeepSeek**（默认） | `https://api.deepseek.com` | `deepseek-flash`（DeepSeek-V4.1-Flash，1M 上下文，支持文本和图片）、`deepseek-v4-pro`（DeepSeek-V4-Pro，1M 上下文） | 在 [platform.deepseek.com](https://platform.deepseek.com) 的 API Keys 页面创建 |
| **OpenAI 兼容** | `https://api.openai.com/v1`（可修改） | 实时读取服务器 `/models` 接口的列表 | 服务商的 API 密钥；本地服务可以留空 |

## 设置步骤 [#set-it-up]

<Steps>
<Step>

### 打开“设置 → AI 服务” [#open-settings--ai-service]

也可以在首次启动引导的“AI 服务”这一步完成。

</Step>
<Step>

### 选择服务商，粘贴密钥 [#pick-a-provider-and-paste-the-key]

如果用的是 OpenAI 兼容服务商，还要填写 Base URL，并从列表里选一个模型。Base URL 要写到 `/chat/completions` 的上一级，通常以 `…/v1` 结尾。

</Step>
<Step>

### 测试连接 [#test-the-connection]

App 会发一个很小的请求并显示结果。如果用的是 DeepSeek，还会显示账户余额。

</Step>
</Steps>

每个对话可以单独切换模型：点输入框上的模型标签，或者输入 `/model`。

## 费用与上下文 [#cost-and-context]

App 会记录每次请求的 token 用量。“设置 → 用量”里能看到缓存命中率、每天的 token 数、用到的模型和工具；对于公布了价格的服务商（DeepSeek），还会估算花了多少钱。

请求的构造方式尽量命中服务商的**前缀缓存**：系统提示词固定不变，工具列表固定，历史记录只追加不修改。命中缓存的输入只需要未命中时的一小部分价格，这一点很划算。

对话长度超过上下文预算后，较早的轮次会自动压缩。预算在“设置 → AI 服务 → 上下文预算”里设置，默认 128k token。

## 没有密钥时测试 [#testing-without-a-key]

如果你在做开发，可以运行插件仓库里的脚本化模拟模型，再把 OpenAI 兼容服务商指向它：

```bash
# 在 pku-harness-plugins 目录下
bun examples/mock-llm/server.ts
# 然后在 App 里：AI 服务 → OpenAI 兼容
#   Base URL: http://10.0.2.2:8788/v1   （模拟器；真机请用电脑的局域网 IP）
#   Model:    mock-agent
```

模拟模型具体做了什么，见[测试](/docs/build/testing)。
