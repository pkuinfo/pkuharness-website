助手需要一个大语言模型才能工作。PKU Harness 不替你运行模型服务，你需要自己提供 API 密钥。密钥保存在手机的密钥库里，请求从你的手机直接发给你选择的模型服务商。以后我们可能会提供托管的模型服务。

模型服务商也由插件提供，这类插件叫作「模型服务商插件」（provider plugin）。因此，社区插件也可以接入更多服务商。

## App 自带的服务商 [#bundled-providers]

App 自带两个模型服务商插件。

| 服务商 | 默认 Base URL | 密钥从哪里来 |
| --- | --- | --- |
| **DeepSeek**（默认） | `https://api.deepseek.com` | 在 [platform.deepseek.com](https://platform.deepseek.com) 的 API Keys 页面创建 |
| **OpenAI 兼容** | `https://api.openai.com/v1`（可修改） | 服务商的 API 密钥；本地服务可以留空 |

DeepSeek 提供两个模型。

- `deepseek-flash`：即 DeepSeek-V4.1-Flash，上下文长度 1M token，可以输入文本和图片。
- `deepseek-v4-pro`：即 DeepSeek-V4-Pro，上下文长度 1M token。

OpenAI 兼容服务商没有固定的模型列表。App 会实时读取服务器 `/models` 接口返回的列表。

## 设置步骤 [#set-it-up]

<Steps>
<Step>

### 打开「设置 → AI 服务」 [#open-settings--ai-service]

也可以在首次启动引导的「AI 服务」这一步完成设置。

</Step>
<Step>

### 选择服务商，粘贴密钥 [#pick-a-provider-and-paste-the-key]

如果使用 OpenAI 兼容服务商，还要填写 Base URL，并从列表里选一个模型。Base URL 要写到 `/chat/completions` 的上一级路径，通常以 `…/v1` 结尾。

</Step>
<Step>

### 测试连接 [#test-the-connection]

App 会发送一个很小的请求并显示结果。如果使用 DeepSeek，App 还会显示账户余额。

</Step>
</Steps>

每个对话可以单独切换模型。点输入框上方的模型标签，或者输入 `/model`，都可以切换。

## 费用与上下文 [#cost-and-context]

App 会记录每次请求消耗的 token 数。在「设置 → 用量」里，你可以看到缓存命中率、每天的 token 数，以及用到了哪些模型和工具。如果服务商公布了价格（例如 DeepSeek），App 还会估算你花了多少钱。

很多服务商会缓存请求开头相同的部分，这叫作**前缀缓存**。命中缓存的输入只收未命中时的一小部分费用。为了尽量命中缓存，App 让每次请求的开头保持不变：系统提示词是固定的，工具列表是固定的，历史记录只在末尾追加，不修改已有内容。

对话的长度超过上下文预算后，较早的轮次会被自动压缩成摘要。预算在「设置 → AI 服务 → 上下文预算」里设置，默认是 128k token。

## 没有密钥时如何测试 [#testing-without-a-key]

开发插件时，你可以不用真实的模型。插件仓库里有一个按脚本回复的模拟模型。运行它，再把 OpenAI 兼容服务商指向它即可。

```bash
# 在 pku-harness-plugins 目录下运行
bun examples/mock-llm/server.ts
# 然后在 App 里打开：AI 服务 → OpenAI 兼容
#   Base URL: http://10.0.2.2:8788/v1   （模拟器的地址；真机请用电脑的局域网 IP）
#   Model:    mock-agent
```

模拟模型的具体行为见[测试](/docs/build/testing)。
