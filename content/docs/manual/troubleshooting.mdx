本页列出使用中常见的问题，以及每个问题的原因和处理方法。

## 校园服务和登录 [#campus-services-and-sign-in]

### 提示「财务门户只能在校园网内访问」 [#finance-portal-campus-network-only]

财务门户（cwfw.pku.edu.cn）只能在北大校园网内访问。请连接校园网（PKU 或 PKU Secure）后再试。App 访问校园服务时直接连接，不使用系统代理。在插件列表中显示「仅限校园网」的插件都有这个限制。

### 提示「无法连接」某个网站 [#cant-reach-a-site]

提示的格式是「无法连接 网站地址（原因）」。可能是这个网站在维护或暂未开放，也可能是它只能在校园网内访问。请检查网络，稍后再试。

### 登录时要求输入验证码 [#asked-for-a-code-at-sign-in]

学校的统一身份认证有时会要求短信验证码、邮件验证码或手机令牌验证码，这是正常的。App 在后台刷新登录状态时也可能遇到这种情况。按提示填写即可，见[校园账号与手机令牌 → 登录时的验证码](/docs/manual/campus-account#verification-codes)。

如果后台刷新时需要验证码，App 会提示「校园登录需要验证码，请打开 App 完成验证」。打开 App 填写即可。

树洞会不定期要求单独的短信验证。查看课表和成绩时，也可能需要手机令牌或短信验证码。

### 提示「账号要求手机令牌，但还没有绑定」 [#authenticator-required-but-not-set-up]

你的账号开启了手机令牌，但本 App 还没有绑定为手机令牌。你可以在验证框中填写你正在使用的令牌 App 显示的验证码，或者把本 App 绑定为手机令牌，见[手机令牌](/docs/manual/campus-account#authenticator)。注意，绑定后原来的令牌会失效。

### 插件显示「需登录」 [#plugin-shows-needs-sign-in]

这个插件需要校园账号。在「设置 → 校园账号」中登录即可。

## AI 服务 [#ai-provider]

### 对话页显示「连接 AI 服务」 [#connect-ai-service-on-the-chat-tab]

还没有设置 AI 服务。点这个按钮，或打开「设置 → AI 服务」，见 [AI 服务](/docs/manual/ai-model)。

### 测试连接时报错 [#errors-when-testing-the-connection]

| 提示 | 处理方法 |
| --- | --- |
| API Key 无效或已停用 | 检查密钥是否完整、是否已在服务商网站上停用 |
| 账户余额不足 | 先在服务商网站充值 |
| 接口地址不对 | 检查 Base URL，通常以 `/v1` 结尾 |
| 请求太频繁 | 稍等片刻再试 |
| 连接超时 / 连不上服务 | 检查网络和 Base URL |

### 无法发送图片 [#cant-send-images]

当前模型不接收图片。例如 DeepSeek-V4-Pro 不接收图片，DeepSeek-V4.1-Flash 可以。附件面板中会提示，并在有可用模型时提供「切换」按钮。

### 助手说「已达到单次回复的步骤上限」 [#step-limit-reached]

一次回复的步骤数有上限。回复「继续」，助手会接着做。

## 提醒和定时任务 [#reminders-and-scheduled-tasks]

### 提醒推迟送达或没有弹出 [#reminders-are-late-or-missing]

1. 打开「设置 → 提醒与通知」。
2. 确认「通知」显示「已允许」，「精确闹钟」显示「提醒会准时送达」。
3. 对「不限制后台」点「开启」，在系统对话框中点「允许」。
4. 点「发送测试提醒」，退到桌面等待 10 秒，确认能收到。

### 定时检查显示「已暂停」 [#scheduled-check-paused]

定时检查连续失败 10 次后会自动暂停。常见原因是需要重新登录、需要校园网或网站在维护。排除原因后，在「日程」页的「提醒与定时任务」中打开它的开关。

## 更新 [#updates]

### 点「更新」后无法安装 [#cant-install-an-update]

第一次通过 App 更新时，Android 会请你允许 PKU Harness 安装应用。打开这个开关后返回 App，系统安装器会继续。如果没有看到这个请求，可以在系统设置的应用信息中找到 PKU Harness，在「安装未知应用」里允许它。

### 提示下载失败 [#download-failed]

检查网络后，在「设置」页顶部点「新版本 X.Y.Z 可用」重试，或在「设置 → 关于 → 检查更新」中重新检查。也可以在[下载页](/download)手动下载 APK 覆盖安装，数据会保留。

## 校园卡 [#campus-card]

### 付款码页面要求切换到「数字卡」 [#payment-code-needs-digital-card]

付款码只能在「数字卡」用卡方式下使用。点「切换到数字卡」即可。切换后实体卡或手机 NFC 可能无法刷卡，可以在「用卡方式」里改回来。

### 充值后余额没有变化 [#balance-unchanged-after-top-up]

在收银台付款后，需要在食堂的 POS 机上刷一次卡，余额才会更新。浴卡充值后，需要拿浴卡到浴卡转存机上贴卡。

## Copilot [#copilot]

### 无法开启 Copilot 无障碍服务 [#cant-turn-on-copilot-accessibility]

对于通过 APK 安装的应用，Android 会把开启无障碍服务列为「受限制的设置」。有两种处理方法：

- 先连接「手机助手」，再在 Copilot 页面点「开启 Copilot 无障碍服务」。
- 在 Copilot 页面点「打开应用信息」，点右上角的 ⋮，选择「允许受限制的设置」，再到系统的无障碍设置中开启「Copilot」。

详见 [Copilot 手机助手](/docs/manual/copilot#enable-accessibility)。

### 「启用 Copilot」开关无法打开 [#enable-copilot-switch-is-disabled]

需要同时满足：手机助手已连接、无障碍服务已开启、至少允许了一个应用，并且已移除「已不可用的应用」。
