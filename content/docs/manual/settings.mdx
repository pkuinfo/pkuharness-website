## 在对话中修改设置 [#changing-settings-in-chat]

这些页面上能改的设置，助手都能改。在对话中直接说，例如「换成深色模式」「界面改成英文」「时区设为 Asia/Shanghai」「关掉触感反馈」「切换到 DeepSeek-V4-Pro」「关闭树洞插件」「Copilot 修改东西前先问我」或「允许 Copilot 使用浏览器」。助手改完后会告诉你这一项原来是什么、现在是什么。设置页面和助手修改的是同一份设置，所以在任一处修改，另一处都会同步显示。

可以修改的包括：

- App 的外观、语言、时区和触感反馈；
- AI 服务、模型和语音输入服务；
- 每个插件的开关和权限；
- 每个插件自己的设置，例如 Copilot 的开关、允许使用的 App 和「允许 AI 查看截图」。

有些事情只能由你自己完成。助手不能读取或填写 API Key，不能替你登录校园账号，也不能授予通知等系统权限。你提出这类要求时，它会打开对应的页面，由你操作。

这些修改由核心插件「设置」完成，它的权限和其他插件一样。默认情况下，助手修改设置时不会询问。如果想每次确认，在「设置 → 插件 → 设置 → AI 可以做什么」中把「修改」设为「每次询问」。

## 云服务 [#cloud]

云服务是一个可选的服务器，只为插件转发和保存加密后的数据。目前用到它的功能是[付款码共享](/docs/manual/campus-card#share-your-payment-code)。校园账号和密码不会离开手机，服务器只认识这台设备的一个匿名密钥。

默认不使用云服务。要开启：

1. 打开「设置 → 云服务」。
2. 选择一个服务器：
   - 「关闭」：不连接任何服务器，依赖云服务的功能不可用。
   - 「官方」：PKU harness 社区运营的实例。
   - 「自建」：你自己或你信任的人部署的开源服务器。在「服务器地址」里填写 `https://` 开头的地址。
3. 点「保存并测试」。连接成功后，页面会显示运营方、支持的服务和限额。

插件要使用云服务，还需要你单独允许。插件第一次需要云服务时，App 会弹出「「插件名」想使用云服务」，列出会离开手机的内容，点「允许」或「暂不」。之后可以在「设置 → 插件 → 插件名」的「云端」一栏中更改，或点「清除此插件的云端数据」。

「本机身份」一栏显示设备指纹，它是这台手机上生成的一对密钥，与校园账号无关。

- 「重置身份」：先删除这台设备在服务器上的数据，再生成新的密钥。进行中的分享会结束。
- 「删除云端数据」：删除这台设备在当前服务器上保存的所有数据。进行中的分享会结束，无法恢复。

## 用量 [#usage]

「设置 → 用量」显示你使用 AI 服务的统计，可以选择「7 天」「30 天」或「全部」。页面包括：

- 今日和本月的 token 用量，以及本月的预估花费。
- 提示缓存的命中率。命中缓存的输入按较低的价格计费。
- 每天的 token 用量、活跃时段和最近 20 周的对话活跃度。
- 用到的插件与工具，以及调用次数和成功率。
- 用到的模型。

花费按服务商公开的价格估算，以服务商的账单为准。

## 时区 [#time-zone]

提醒、日程、记账和助手都按这个时区计时。这一行的副标题显示当前使用的时区和它此刻与 UTC 的时差。

默认是「跟随系统」：时区随手机的系统设置变化，例如出国时会自动切换。要固定使用某个时区，打开「设置 → 时区」，搜索城市、国家或时区名称，然后点选。

## 导出数据 [#export-data]

点「设置 → 导出数据」，App 会生成一个 JSON 文件，并打开系统的分享面板，你可以把它保存或发送到别处。文件包括提醒、待办、课表、看板与设置，不包括密码和 API Key。

## 清除所有数据 [#erase-all-data]

1. 点「设置 → 清除所有数据」。
2. 在确认对话框中点「清除」。

提醒、待办、课表、看板、对话和已保存的密钥（包括校园账号密码和 API Key）都会从手机上删除，无法恢复。之后 App 会回到首次设置的介绍页。

- 「关于 PKU harness」：App 版本和正在使用的在线更新，官方网站和源代码的链接，作者和贡献者，我们永久开源、永久免费的承诺，以及「用户协议」和「隐私政策」。网站上的版本见[用户协议](/terms)和[隐私政策](/privacy)。隐私政策说明了哪些数据会发给 AI 服务商、语音输入服务、学校系统和云服务。
