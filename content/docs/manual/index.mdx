本手册说明 PKU Harness Android App 1.0.20 版的用法。每一页讲一个部分，步骤中引用的按钮和菜单名称与 App 里显示的一致。

PKU Harness 是一个帮你处理校园事务的 Android 应用。你用北大的学号和密码登录一次，再接入一个 AI 模型服务，就可以在对话里让助手查询校园卡余额、同步课表、设置提醒等。每一项连接校园服务的功能都由一个插件提供。

如果你是第一次使用，请先阅读 [AI 服务](/docs/manual/ai-model)：接入模型服务之前，助手什么也做不了。那一页一步一步说明了怎样申请 Key。

## App 的四个标签页 [#the-four-tabs]

App 底部有四个标签页。

| 标签页 | 内容 |
| --- | --- |
| **对话** | 和助手对话，让它查询信息或替你操作 |
| **看板** | 一组小组件，显示余额、教学周等数字 |
| **日程** | 课表、待办、提醒和定时任务 |
| **设置** | 账号、AI 服务、插件、通知和数据 |
