App 中每一项连接校园服务的功能都由一个插件提供，例如「校园钱包」「教学网」「树洞」。本页说明怎样管理插件，以及怎样控制助手可以替你做哪些操作。

## 插件列表 [#the-plugin-list]

打开「设置 → 插件」。页面顶部可以搜索，下面按四组列出所有插件。

| 分组 | 内容 |
| --- | --- |
| 校园服务 | 连接校园服务和其他功能的插件，可以单独开关 |
| 手机操作 | Copilot，在这台手机上替你操作其他 App，见 [Copilot](/docs/manual/copilot) |
| 系统能力 | App 本身的一部分，例如看板、日程、提醒，始终开启 |
| AI 服务 | 模型服务商，例如 DeepSeek，在「设置 → AI 服务」里切换 |
| 远程插件 | 通过 MCP 连接的第三方服务 |

每个插件旁边显示它的状态：「已开启」「已关闭」「需登录」（要先登录校园账号）、「仅限校园网」或「暂不可用」（这台设备不支持它需要的功能）。

插件分为两类来源。**内置插件**随 App 发布，可以关闭，但不能删除。**社区插件**是你通过链接自己安装的插件，可以删除。

## 插件页面 [#a-plugins-page]

在列表中点按一个插件，打开它的页面。页面上依次有以下内容（有些插件没有其中某几项）。

- **启用插件**：开关。关闭后，助手和看板都无法使用这个插件。
- **打开**：插件自己的页面，例如「校园钱包」插件的「校园卡付款码」，「手机令牌」插件的「手机令牌」。
- **AI 可以做什么**：四类操作的权限，见下一节。
- **云端**：插件是否可以使用云服务，见[设置与数据](/docs/manual/settings#cloud)。
- **看板组件**：这个插件提供的看板组件。
- **能力**：插件提供的全部工具，以及每个工具属于哪类操作。
- **访问范围**：插件可以访问的校园服务和网站。
- **来源**：通过链接安装的插件和内置的插件文档会显示版本、更新和移除选项。

## 权限 [#permissions]

插件的每个工具都属于以下四类操作之一。

| 操作 | 例子 |
| --- | --- |
| 读取 | 查询余额、课表、公告等 |
| 修改 | 创建提醒、改设置、提交表单 |
| 资金 | 充值、缴费、付款码 |
| 公开 | 发帖、评论等他人可见的操作 |

在插件页面的「AI 可以做什么」里，你可以为每类操作选择一种权限。

| 权限 | 含义 |
| --- | --- |
| 直接执行 | 助手直接完成，不打扰你 |
| 每次询问 | 助手执行前先请你确认，见[对话 → 确认助手的操作](/docs/manual/chat#confirm-the-assistants-actions) |
| 禁止 | 助手不能这样做 |

这些权限只限制助手。你在界面上亲手点击的操作不受限制。

默认权限如下。

- 内置插件和来自官方仓库 `pkuinfo/pku-harness-plugins` 的插件，默认全部为「直接执行」。少数插件有自己的默认值，例如「Copilot 手机助手」的修改、资金、公开操作默认「每次询问」，「付款码共享」的资金操作默认「每次询问」。
- 社区插件和远程插件的修改、资金、公开操作，默认至少为「每次询问」。

定时任务只能使用读取类工具，也不能使用设置为「每次询问」的工具。

也可以让助手开关插件或修改权限，例如「Copilot 修改东西前先问我」，见[设置 → 在对话中修改设置](/docs/manual/settings#changing-settings-in-chat)。

## 通过链接安装插件 [#install-from-a-link]

社区插件是一个包含 `PLUGIN.md` 文件的 GitHub 文件夹。安装方法有两种。

**点按安装链接。** 网站[插件市场](/marketplace)上的安装链接以 `pkuharness://plugin?src=` 开头。在手机上点按它，App 会打开「添加插件」页面并填好链接。

**粘贴链接。**

1. 打开「设置 → 插件」，在「远程插件」一组中点「添加远程插件」。
2. 在「链接」里粘贴插件的 GitHub 文件夹链接，例如 `github.com/owner/repo/tree/main/my-plugin`。这里也可以填 MCP 服务地址。
3. 点「检查」。App 会读取插件，但还不会安装。
4. 查看它的信息：作者和版本，标签「官方」或「社区」，「它能访问的」校园服务、网站和 App 功能，以及「它能做的」全部工具。
5. 确认无误后，点「安装」。

社区插件的工具返回的内容只作为数据交给助手，不会被当作指令。

## 更新插件 [#update-a-plugin]

通过链接安装的插件默认自动更新。在插件页面的「来源」一栏中：

- 「检查更新」会立即检查一次。
- 「自动更新」开关可以关闭自动更新。
- 如果新版本需要更多权限，它不会自动安装，而是显示「版本 X 需要更多权限」。点「查看并更新」查看新版本，再决定是否安装。
- 「退回到版本 X」可以回到上一个版本。

内置插件随 App 提供，从官方链接自动更新。

## 移除插件 [#remove-a-plugin]

在插件页面底部点「移除插件」。只有你通过链接安装的插件和远程插件可以移除。内置插件只能关闭。

## 插件市场 [#marketplace]

在「设置 → 插件」的「远程插件」一组中点「插件市场」，可以浏览插件，并按「全部」「内置」「远程」筛选。已经内置的插件显示「已内置」，点按会打开它的插件页面。完整的插件市场也可以在网站上浏览：[插件市场](/marketplace)。
