第一次打开 PKU Harness 时，App 会先显示几页介绍，请你同意用户协议，然后带你完成六个设置步骤。本页按顺序说明每一步。

每完成一步，进度都会保存。如果中途退出 App，下次打开时会回到同一步。要返回上一步，点左上角的返回箭头，或按 Android 的返回键。页面顶部的进度条显示当前在第几步。

<Callout title="先准备好 AI 服务">
  对话页的所有功能都需要一个 AI 模型服务，App 本身不附带。如果你还没有 API Key，请先阅读 [AI 服务](/docs/manual/ai-model)，那里一步一步说明了怎样在 DeepSeek、阿里云百炼或百度千帆申请 Key。整个过程大约十分钟，用手机浏览器就能完成。
</Callout>

## 介绍页和用户协议 [#intro-and-terms]

介绍页共五页。左右滑动或点「继续」翻页，点「跳过介绍」直接到最后一页。

最后一页有一个复选框：「我已阅读并同意《用户协议》和《隐私政策》……」。点下方的「用户协议」或「隐私政策」可以阅读全文。勾选后，「同意并继续」才能点按。

同意后，AI 可以在你授予的权限内代你操作校园服务。每个插件的权限之后都可以修改，见[插件与权限](/docs/manual/plugins#permissions)。

## 第 1 步：连接 AI 服务 [#step-1-connect-an-ai-provider]

助手需要一个大模型才能工作。这一步需要一个模型服务商提供的 API Key。API Key 是一串类似密码的长字符，通常以 `sk-` 开头。

1. 如果有多个 AI 服务插件，在顶部选择一个：「DeepSeek」或「OpenAI 兼容」。默认是 DeepSeek。使用阿里云百炼、百度千帆等服务时，选「OpenAI 兼容」。
2. 选择「OpenAI 兼容」时，需要填写「接口地址（Base URL）」。各服务商的地址见 [AI 服务](/docs/manual/ai-model#recommended-providers)。
3. 在「API Key」里粘贴密钥。右侧的按钮可以从剪贴板粘贴，以及显示或隐藏密钥。
4. 点「验证并连接」。App 会用这个密钥向服务商发送一次请求。成功时显示「已连接，可用 N 个模型」；失败时会说明原因，例如密钥无效或账户余额不足。
5. 在「模型」下选择一个模型。如果服务商没有返回模型列表，在「模型 ID」里填写模型名称。
6. 点「继续」。

密钥只保存在这台手机上，只会发送给你选择的服务商。

## 第 2 步：登录北大账号 [#step-2-sign-in-to-pku]

1. 在「学号 / 职工号」和「密码」里填写门户使用的 IAAA 账号。
2. 点「登录」。
3. 如果学校要求短信验证码或手机令牌验证码，App 会弹出输入框。填写后点「验证」。
4. 登录成功后，页面显示「你好，」加上你的姓名。点「继续」。

如果显示网络错误，可能是需要连接校园网的服务暂时访问不到。详见[常见问题](/docs/manual/troubleshooting)。

## 第 3 步：设置手机令牌 [#step-3-authenticator]

这一步把 App 设为你的 IAAA 手机令牌。之后学校登录要求手机令牌验证码时，App 会自动填写，看板上也会出现一个「手机令牌」组件。这个组件平时隐藏验证码，点按后才显示，见[校园账号与手机令牌](/docs/manual/campus-account#authenticator)。

这一步需要先登录北大账号。如果第 2 步没有登录，这里只显示说明和「继续」按钮。

1. 阅读页面上的说明。绑定后，你之前在其他 App（如 FreeOTP、Google Authenticator）里设置的手机令牌会失效。
2. 勾选「我已了解，之前绑定的手机令牌会失效」。
3. 点「发送短信验证码」。验证码会发到账号绑定的手机号。
4. 在「短信验证码」里填写收到的验证码，点「完成绑定」。

暂时不想设置的话，点「暂不设置」。之后可以在「设置 → 插件 → 手机令牌」中完成。

## 第 4 步：选择插件 [#step-4-choose-plugins]

页面把内置插件分为「校园服务」「效率」「系统」三组。每一行右侧的开关用于开启或关闭插件，改动立即生效。

- 有些插件带有标签。「需登录」表示需要先登录北大账号，「仅校园网」表示只能在校园网内使用，「通知」和「后台」表示它会发送通知或在后台运行。
- 「系统」组里的插件是 App 本身的一部分，始终开启。

选好后点「继续」。之后随时可以在「设置 → 插件」中修改。

## 第 5 步：让提醒准时送达 [#step-5-get-reminders-on-time]

提醒和定时检查在你的手机上运行，到点由系统闹钟唤起。这一步有三项。

| 项目 | 标签 | 怎么做 |
| --- | --- | --- |
| 「通知」 | 必需 | 点「允许」，在系统弹窗中允许通知。如果通知之前被关闭，按钮会显示「去设置」 |
| 「准时提醒」 | 必需 | 点「开启」，在系统的「闹钟和提醒」设置中允许 PKU Harness |
| 「不限制后台」 | 推荐 | 点「允许」，在弹出的系统对话框中点「允许」 |

不开启通知，提醒和预警都不会弹出。不开启准时提醒，系统可能把提醒推迟几分钟甚至更久。不限制后台，早上查余额这类定时检查才能在后台准时运行。

这些权限之后可以在「设置 → 提醒与通知」中修改。

## 第 6 步：让助手替你操作其他 App [#step-6-copilot]

这一步介绍「Copilot」。它让助手打开并操作你手机上的其他 App，例如浏览器或外卖 App。这一步只在 Android 上出现。

页面列出 Copilot 需要的几项，并标明「已完成」或「待设置」：

- 「手机助手（无线调试配对）」
- 「无障碍权限」
- 「允许使用的 App」

点「设置 Copilot」会打开 Copilot 页面，在那里完成设置。回到这一步时，如果都已完成，页面显示「Copilot 已就绪」，点「继续」即可。如果手机助手已经连接、但无障碍没有开启，可以直接点这里的「开启无障碍」。

设置大约需要几分钟，会用到 Android 的「开发者选项」。如果你对这些不熟悉，可以先点「稍后设置」，有空时再按照 [Copilot 手机助手](/docs/manual/copilot)一步一步完成。之后也可以在对话中输入 `/copilot` 开始设置。

## 完成 [#finish]

最后一页汇总设置结果：「AI 服务」是否已连接，「北大账号」是否已登录，开启了多少「校园服务」，「提醒」能否准时送达，以及「Copilot」是否已就绪。

如果已经连接 AI 服务，「可以这样开始」下面会列出几个问题，例如「校园卡还剩多少钱？」。点按一个问题，它会被填进对话页的输入框，由你决定是否发送。点「开始使用」进入对话页。

## 「稍后设置」的作用 [#what-set-up-later-does]

第 1、2、4、5、6 步底部有「稍后设置」按钮，第 3 步是「暂不设置」。点按后直接进入下一步，这一步填写的内容不会保存。跳过的项目之后都可以补上。

| 步骤 | 之后在哪里设置 |
| --- | --- |
| 连接 AI 服务 | 设置 → AI 服务 |
| 登录北大账号 | 设置 → 校园账号 |
| 设置手机令牌 | 设置 → 插件 → 手机令牌 |
| 选择插件 | 设置 → 插件 |
| 提醒权限 | 设置 → 提醒与通知 |
| Copilot | 在对话中输入 `/copilot`，或设置 → 插件 → Copilot 手机助手 |

没有连接 AI 服务也可以进入 App，但无法对话，对话页会显示「连接 AI 服务」按钮。
