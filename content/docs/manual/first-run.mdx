第一次打开 PKU Harness 时，App 先显示几页介绍，请你同意用户协议，然后带你完成五个设置步骤。本页按顺序说明每一步。

设置进度在每一步之后都会保存。如果中途退出 App，下次打开时会回到你停下的那一步。点左上角的返回箭头，或按 Android 的返回键，可以回到上一步。页面顶部的进度条显示你在第几步。

## 介绍页和用户协议 [#intro-and-terms]

介绍共五页，左右滑动或点「继续」翻页，点「跳过介绍」直接到最后一页。

最后一页底部有一个复选框，内容是「我已阅读并同意《用户协议》和《隐私政策》……」。点下面的「用户协议」或「隐私政策」可以阅读全文。勾选后，「同意并继续」按钮才能点按。

同意之后，AI 可以按你授予的权限代你操作校园服务。各插件的权限可以在之后修改，详见[插件与权限](/docs/manual/plugins#permissions)。

## 第 1 步：连接 AI 服务 [#step-1-connect-an-ai-provider]

助手需要一个大模型才能工作。

1. 如果有多个 AI 服务插件，先在顶部选择一个：「DeepSeek」或「OpenAI 兼容」。
2. 选「OpenAI 兼容」时，填写「接口地址（Base URL）」，通常以 `/v1` 结尾。
3. 在「API Key」里粘贴你的密钥。右侧的按钮可以粘贴剪贴板内容，或显示、隐藏密钥。
4. 点「验证并连接」。App 会用这个密钥向服务商请求一次。成功时显示「已连接，可用 N 个模型」，失败时显示原因，例如「API Key 无效或已停用」或「账户余额不足」。
5. 在「模型」下选择一个模型。如果服务商没有返回模型列表，就在「模型 ID」里填写模型名称。
6. 点「继续」。

密钥只保存在本机，只发给你选择的服务商。各服务商的说明见 [AI 服务](/docs/manual/ai-model)。

## 第 2 步：登录北大账号 [#step-2-sign-in-to-pku]

1. 在「学号 / 职工号」和「密码」里填写门户使用的 IAAA 账号。
2. 点「登录」。
3. 如果学校要求短信验证码或手机令牌验证码，App 会弹出输入框。填写后点「验证」。
4. 登录成功后，页面显示「你好，」加上你的姓名。点「继续」。

如果显示网络错误，可能是需要连接校园网的服务暂时访问不到。详见[常见问题](/docs/manual/troubleshooting)。

## 第 3 步：设置手机令牌 [#step-3-authenticator]

这一步把本 App 绑定为 IAAA 的手机令牌。绑定后，学校登录要求手机令牌验证码时，App 会自动填写，看板上也会多一个显示当前验证码的「手机令牌」组件。

这一步需要先登录北大账号。如果上一步没有登录，这里只显示说明和「继续」按钮。

1. 阅读页面上的说明。绑定后，之前在其他 App（如 FreeOTP、Google Authenticator）中绑定的手机令牌会失效。
2. 勾选「我已了解，之前绑定的手机令牌会失效」。
3. 点「发送短信验证码」。验证码会发到你账号绑定的手机上。
4. 在「短信验证码」里填写收到的数字，点「完成绑定」。

如果不想绑定，点「暂不设置」。之后可以在「设置 → 插件 → 手机令牌」里完成，详见[校园账号与手机令牌](/docs/manual/campus-account#authenticator)。

## 第 4 步：选择插件 [#step-4-choose-plugins]

页面按「校园服务」「效率」「系统」三组列出内置插件。用每一行右侧的开关启用或关闭插件，改动立即生效。

- 有些插件带有标签：「需登录」表示要先登录北大账号，「仅校园网」表示只能在校园网内使用，「通知」和「后台」表示它会发送通知或在后台运行。
- 「系统」组的插件是 App 本身的一部分，始终开启，不能关闭。

选好后点「继续」。之后可以随时在「设置 → 插件」里修改。

## 第 5 步：让提醒准时送达 [#step-5-get-reminders-on-time]

提醒和定时检查在手机上运行，到点由系统闹钟唤起。这一步有三项。

| 项目 | 标记 | 操作 |
| --- | --- | --- |
| **通知** | 必需 | 点「允许」，在系统弹窗中允许通知。如果已被拒绝，按钮变为「去设置」 |
| **准时提醒** | 必需 | 点「开启」，在系统的「闹钟和提醒」设置中允许 PKU Harness |
| **不限制后台** | 推荐 | 点「允许」，在弹出的系统对话框中点「允许」 |

不开启通知，提醒和预警都不会弹出。不开启准时提醒，系统可能把提醒推迟几分钟甚至更久。「不限制后台」让早上查余额这类定时检查能在后台按时运行。

点「继续」进入最后一页。之后可以在「设置 → 提醒与通知」里修改这些权限。

## 完成 [#finish]

最后一页显示设置结果：「AI 服务」是否已连接，「北大账号」是否已登录，开启了几个「校园服务」，以及「提醒」能否准时送达。

如果已经连接 AI 服务，下面的「可以这样开始」会列出几个问题，例如「校园卡还剩多少钱？」。点按其中一个，它会被填进对话页的输入框，由你决定是否发送。点「开始使用」进入对话页。

## 「稍后设置」的作用 [#what-set-up-later-does]

第 1、2、4、5 步底部有「稍后设置」按钮，第 3 步是「暂不设置」。点它会跳到下一步，这一步填写的内容不会保存。跳过的项目可以在之后补上。

| 步骤 | 之后在哪里设置 |
| --- | --- |
| 连接 AI 服务 | 设置 → AI 服务 |
| 登录北大账号 | 设置 → 校园账号 |
| 手机令牌 | 设置 → 插件 → 手机令牌 |
| 选择插件 | 设置 → 插件 |
| 提醒权限 | 设置 → 提醒与通知 |

不连接 AI 服务也可以进入 App，但对话页无法使用，页面会显示「连接 AI 服务」按钮。
