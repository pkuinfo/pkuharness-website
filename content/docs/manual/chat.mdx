「对话」页是你和助手交谈的地方。助手会调用已开启插件的工具来查询信息或替你操作，也可以在对话里显示表单、选择器和数据卡片。本页说明这个页面上的各项操作。

使用对话页之前，需要先连接一个 AI 服务。没有连接时，页面会显示「连接 AI 服务」按钮，点按后进入「设置 → AI 服务」。

## 发送消息 [#send-a-message]

1. 在底部的输入框里输入内容。内容较长时，点输入框右上角的展开按钮可以打开全屏编辑器。想用说的，点麦克风，见[语音输入](/docs/manual/voice-input)。
2. 点发送按钮。

你用什么语言提问，助手就用什么语言回答。

新对话的空白页上列出了几个示例问题，例如「今天有什么课？」。点按一个就会直接发送。

助手回复时，会显示它正在做什么，例如「思考中」或「正在调用」某个工具。回复结束后：

- 如果模型输出了思考过程，回复上方会出现「思考了 N 秒」，点按可以展开或收起。
- 如果助手用了工具，会显示「用了 N 个工具」和工具名称。回答正文出现后，这部分会自动折叠，点按可以重新展开。
- 回复下方有复制按钮。最后一条回复还有重新生成按钮。点左侧的小图标可以显示本次回复的统计：模型、用时和 token 数。

如果你在回复进行中切到别的 App，回复完成后 App 会发一条「回复好了」的通知。

## 停止回复和排队发送 [#stop-and-queue]

助手回复时，发送按钮的位置会出现停止按钮。点按它会停止当前回复，回复下方显示「已停止」。

回复进行中，你仍然可以输入下一条消息并点「排队发送」。排队的消息会在当前回复结束后依次发送。如果当前回复被停止或出错，排队的消息会暂停，输入框上方显示「回复中断，排队的消息已暂停」，点「继续发送」即可恢复。点按一条排队的消息可以把它放回输入框。

单次回复的步骤数没有上限。助手会一直做到任务完成或你按停止。在长任务中（例如用 Copilot 点单），上下文快满时较早的步骤会被压缩成摘要，然后任务继续。

## 附件 [#attachments]

点输入框左下角的「+」，打开「添加到消息」面板。

| 选项 | 说明 |
| --- | --- |
| 拍照 | 用相机拍一张照片 |
| 相册 | 从相册选择图片 |
| 文件 | PDF、Word、Excel、PowerPoint、音频和文本文件 |
| 输入命令 | 在输入框中输入 `/`，打开命令菜单 |

每条消息最多带 8 个附件。文本文件最大 200 KB，文档最大 30 MB，音频最大 50 MB。只有支持图片的模型才能接收图片。当前模型不支持图片时，面板会提示，并在有可用模型时提供「切换」按钮。例如 DeepSeek-V4.1-Flash 支持图片，DeepSeek-V4-Pro 不支持。

### 文档和音频 [#documents-and-audio]

PDF、Word、Excel 和 PowerPoint 文件会在你的手机上读成文字。文件本身不会上传，助手拿到的是文字。长文档只有开头部分随消息发送，助手需要时会翻到后面或在文档里搜索。引用数字、日期和金额时，它会照原文写。点按附件可以预览助手看到的文字。

有些文件读不出来，App 会说明原因：只有图片的扫描版 PDF（请改为拍下页面）、有密码保护的文件，以及损坏的文件。

音频文件由你的[语音输入](/docs/manual/voice-input#transcribe-an-audio-file)服务转成文字，助手读取转写结果。「阿里云百炼（实时）」只能处理实时语音，转写音频文件请选择硅基流动。

文档里的文字被当作数据。如果文件里写着要助手做什么，助手不会照做。

### 很长的粘贴文本 [#long-pasted-text]

粘贴很长的文本时，输入框下方会提示内容太长，点「转为附件」可以把它作为附件发送。

## 命令 [#commands]

在输入框开头输入 `/`，会弹出命令菜单。继续输入可以筛选，点按一项即可执行。命令也可以用中文别名，例如 `/新对话`。

| 命令 | 作用 |
| --- | --- |
| `/new` | 开始新对话 |
| `/sessions` | 查看全部对话 |
| `/rename 新标题` | 重命名当前对话 |
| `/retry` | 重新生成上一条回复 |
| `/copy` | 复制上一条回复 |
| `/export` | 把对话导出为 Markdown 分享 |
| `/compact` | 压缩较早的对话，腾出上下文 |
| `/context` | 查看上下文占用 |
| `/model` | 切换模型 |
| `/memory` | 查看 AI 记住了什么 |
| `/usage` | 查看 token 用量 |
| `/tasks` | 查看定时任务和提醒 |
| `/plugins` | 管理插件 |
| `/help` | 列出所有命令 |

插件也会添加自己的命令，例如 `/balance`（查校园卡余额）、`/canteen`（现在去哪个食堂）、`/homework`（查看教学网上还没交的作业）和 `/share`（分享付款码给朋友）。输入 `/help` 可以看到当前可用的全部命令。

## 模型和上下文 [#model-and-context]

输入框下方的模型标签显示当前使用的模型。点按它可以选择其他模型。新选择的模型从下一条消息起用于这个对话，也会成为新对话的默认模型。

模型支持时，选择面板顶部还有「思考强度」：「自动」（默认）在规划任务时认真思考，在用 Copilot 操作手机时每一步快速思考；也可以固定为「低」「高」或「最高」。助手用你消息的语言回复：用中文问就用中文答，即使 App 界面是英文。

模型标签旁边的圆环显示当前对话占用了多少上下文预算。点按它可以看到各部分的占用和压缩次数。对话超过预算时，较早的内容会被自动压缩成摘要，长任务进行到一半时也会这样做。对话里会显示「已压缩 N 条消息」，点按可以查看摘要。预算在「设置 → AI 服务 → 上下文预算」里设置，默认使用模型的完整上下文，见 [AI 服务 → 上下文预算](/docs/manual/ai-model#context-budget)。

## 编辑和复制消息 [#edit-and-copy-messages]

- **编辑你发出的消息**：长按这条消息，点「编辑」。内容会回到输入框，上方显示「编辑消息 · 发送后将替换这条及之后的内容」。修改后发送，这条消息之后的对话会被替换。点输入框上方的关闭按钮可以取消编辑。
- **复制你发出的消息**：长按这条消息，点「复制」。
- **复制助手的回复**：点回复下方的复制按钮，或输入 `/copy` 复制最后一条回复。

## 对话列表 [#chats]

点对话页左上角的菜单按钮，打开对话列表。对话按「置顶」「今天」「昨天」「7 天内」「更早」分组，顶部可以搜索。

- 点按一个对话即可打开。
- 长按一个对话，可以「重命名」「置顶」或删除。
- 向左滑动一个对话可以删除。删除后 5 秒内可以点「撤销」恢复。

新对话的标题由 App 根据内容自动生成。点对话页顶部的标题可以直接修改。对话页右上角的「+」用于开始新对话。

## 助手能做什么 [#what-the-assistant-can-do]

助手能做的事情取决于你开启了哪些插件。例如：

- 查询校园卡余额、网费、成绩、空闲教室、食堂人流和校园通知。
- 从学校同步课表，创建待办、提醒和定时检查。
- 把数字放到看板上。
- 阅读和搜索你附上的文档。
- 修改 App 的设置，例如主题、语言、时区、模型，以及插件的开关和权限，见[设置 → 在对话中修改设置](/docs/manual/settings#changing-settings-in-chat)。
- 设置好 [Copilot](/docs/manual/copilot) 后，操作手机上的其他 App。
- 在对话里显示表单或选择器，让你填写或选择后点「提交」。

有些操作只能由你本人在 App 界面上完成，助手不能代劳。例如出示校园卡付款码，在教学网交作业时选择文件并提交，以及填写密码和 API Key。

插件的完整列表见「设置 → 插件」，详见[插件与权限](/docs/manual/plugins)。

## 确认助手的操作 [#confirm-the-assistants-actions]

每个插件的每一类操作都有一个权限设置：「直接执行」「每次询问」或「禁止」。设置为「每次询问」的操作，助手执行前会弹出确认面板，标题是「AI 请求执行」，并说明来自哪个插件。

- 点「允许」执行这一次。
- 点「拒绝」不执行，助手会收到被拒绝的结果。
- 点「允许，以后同类操作不再询问」会执行，并把这个插件这一类操作改为「直接执行」。Copilot 操作手机应用时的确认面板没有这个选项。

权限的设置方法见[插件与权限](/docs/manual/plugins#permissions)。
