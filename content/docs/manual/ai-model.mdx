助手需要一个大模型才能工作。PKU Harness 不提供模型服务，你需要使用自己的 API Key。本页说明怎样接入和切换模型服务。

API Key 保存在手机的系统安全存储中，只发给你选择的服务商。对话请求从你的手机直接发往服务商。

## 可用的服务商 [#providers]

模型服务商也由插件提供。App 内置两个。

| 服务商 | 接口地址 | API Key 从哪里获得 |
| --- | --- | --- |
| **DeepSeek**（默认） | `https://api.deepseek.com`，不可修改 | 在 [platform.deepseek.com](https://platform.deepseek.com) 的 API Keys 页面创建 |
| **OpenAI 兼容** | 默认 `https://api.openai.com/v1`，可以修改 | 你使用的服务商提供 |

DeepSeek 提供两个模型。

| 模型 | 说明 |
| --- | --- |
| DeepSeek-V4.1-Flash（默认） | 快速、经济，适合日常任务。可以接收图片 |
| DeepSeek-V4-Pro | 推理能力更强，适合复杂任务。不接收图片 |

「OpenAI 兼容」可以连接任何支持 OpenAI Chat Completions 接口的服务。它没有固定的模型列表，App 会读取服务商返回的列表。

## 接入或修改 [#set-it-up]

你可以在[首次设置](/docs/manual/first-run#step-1-connect-an-ai-provider)中接入，也可以之后在设置里修改。

1. 打开「设置 → AI 服务」。
2. 点选一个服务商。
3. 使用「OpenAI 兼容」时，填写「Base URL」，通常以 `/v1` 结尾。
4. 在「API Key」里填写密钥。已保存的密钥旁显示「已保存在本机安全存储」。
5. 在「模型」列表中选择一个模型，或在「模型 ID」里直接填写模型名称。
6. 点「保存并测试连接」。App 会发一条很短的测试消息，成功时显示「连接成功」和模型的回复。只想保存、不测试时，点「仅保存」。

选择 DeepSeek 并保存密钥后，服务商列表下方会显示「账户余额」，包括赠送和充值的金额。点「刷新余额」可以重新获取。

## 在对话中切换模型 [#switch-models-in-a-chat]

在对话页点输入框下方的模型标签，或输入 `/model`，可以选择其他模型。新模型从下一条消息起用于这个对话，也会成为新对话的默认模型。详见[对话 → 模型和上下文](/docs/manual/chat#model-and-context)。

## 上下文预算 [#context-budget]

「设置 → AI 服务」底部的「上下文预算」可以选择「32k」「64k」「128k」「256k」或「不限」，默认是 128k。

对话超过预算（或模型上下文长度的 80%）时，App 会把较早的内容压缩成摘要。预算越小，回复越快、费用越低，但助手能直接看到的历史越短。

## 用量和费用 [#usage-and-cost]

「设置 → 用量」显示 token 用量、活跃时段和常用工具，可以按「7 天」「30 天」或「全部」查看。对于公开了价格的模型（例如 DeepSeek），页面会按公开价格估算花费。估算值仅供参考，以服务商的账单为准。详见[设置与数据 → 用量](/docs/manual/settings#usage)。
