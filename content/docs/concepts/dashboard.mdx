看板（dashboard）标签页由 `dashboard` 插件提供。里面是一个有序的小组件（widget）列表，两类小组件混排在一起。你告诉助手想看哪些数字（“显示我的校园卡余额和下一班校车”），它就会搭建或修改看板。你也可以长按小组件来调整顺序、改变大小或删除，还可以从小组件库里添加插件提供的小组件。

| 类型 | 由谁绘制 | 数据来源 |
| --- | --- | --- |
| **助手搭建** `{ spec, bindings }` | 助手写一份[生成式界面](/docs/concepts/generative-ui) spec（`dashboard.upsertWidget`） | `bindings`：状态路径 → 读取类工具 |
| **插件提供** `{ source: { plugin, widget, config? } }` | 插件自己的原生组件（`contributes.widgets`），外面包一层错误边界 | 组件内部调用 `host.useToolData(...)` |

助手会先查看 `dashboard.catalog`。如果有合适的插件小组件，就直接放上去（`dashboard.addPluginWidget`），没有合适的才自己搭。两种小组件的外框都由看板来画：标题、数据新鲜度和长按菜单。

## 小组件模型 [#widget-model]

```ts
type Widget = {
  id: string;
  title: string;
  size: 'sm' | 'md' | 'lg';           // sm = 半宽小块，md = 全宽，lg = 全宽大卡片
  spec: Record<string, unknown>;      // json-render spec（插件小组件为空）
  bindings: Record<string, Binding>;  // 状态中的 JSON pointer → 数据源
  source?: { plugin: string; widget: string; config?: Record<string, unknown> };
  position: number;
  createdAt: number;
  updatedAt: number;
};

type Binding = {
  tool: string;            // 只读工具 id，例如 "calendar.today"
  args?: Record<string, unknown>;
  path?: string;           // 结果中的点路径；为空表示整个结果
  ttlMinutes?: number;     // 0 – 1440，默认 5
};
```

下面是一个由助手搭建、显示今天课程的小组件：

```json
{
  "title": "下一节课",
  "size": "md",
  "spec": {
    "root": "col",
    "elements": {
      "col": { "type": "Column", "props": { "gap": "sm" }, "children": ["h", "t"] },
      "h": { "type": "Heading", "props": { "text": { "$template": "今天共 ${/today/count} 节课" }, "size": "md" } },
      "t": { "type": "Text", "props": { "text": { "$template": "下一节：${/today/next/name} ${/today/next/time}" }, "tone": "muted", "size": null } }
    }
  },
  "bindings": { "/today": { "tool": "timetable.today", "ttlMinutes": 1 } }
}
```

## 刷新由宿主负责 [#refresh-owned-by-the-host]

所有读取类工具的结果都存在**同一个以“工具 + 参数”为键的存储**里，助手搭建的小组件、插件小组件、插件页面和定时检查都共用它。用过 TanStack Query 的话，这就是同一套模型：

- 上一次的值会持久化。冷启动后数字立刻显示出来，并标明是多久前的数据（“3 分钟前”）。只有从来没拉取过数据时才会显示骨架屏。
- 超过 TTL（默认 5 分钟）后数据就算过期。**当前聚焦页面上**的过期查询会在页面获得焦点、App 回到前台时重新拉取，页面可见期间也会定时刷新。隐藏的标签页和后台从不轮询。
- 下拉刷新会强制刷新当前页面上的所有查询。同时发出的相同请求共用一个 promise。
- 刷新失败时保留上一次的值，并加上标记（“刷新失败 · 10 分钟前”）。
- 定时检查也写入这个存储，所以后台的余额检查会顺带更新小组件。

因此插件小组件**不得**自己设定时器轮询。用 `host.useToolData` 加载数据，按数据变化的快慢选择 TTL：余额类 5–15 分钟，变化慢的数据 60 分钟以上。

## 编写插件小组件 [#writing-a-plugin-widget]

```tsx
import type { PluginWidgetProps } from '@pku-harness/sdk';
import { View } from 'react-native';

type Crowd = { name: string; percent: number }[];

export function CrowdWidget({ host, size }: PluginWidgetProps) {
  const { Text, Skeleton } = host.components;
  const t = host.useTheme();
  const data = host.useToolData<{ canteens: Crowd }>('canteen.crowd', {}, { ttlMinutes: 2 });
  if (data.status === 'loading') return <Skeleton width="60%" height={20} />;
  if (!data.value) return <Text tone="muted">{data.error ?? '暂无数据'}</Text>;
  const list = data.value.canteens.slice(0, size === 'sm' ? 3 : 6);
  return (
    <View style={{ gap: t.spacing.xs }}>
      {list.map((c) => (
        <Text key={c.name} variant="callout">{`${c.name} ${c.percent}%`}</Text>
      ))}
    </View>
  );
}
```

在 `contributes.widgets` 下注册它，并写一段给助手看的 `description`，助手挑选小组件时读的就是这段描述。详见 [UI 扩展](/docs/build/ui#widgets)。
