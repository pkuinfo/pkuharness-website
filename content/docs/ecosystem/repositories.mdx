所有代码都在 GitHub 组织 [`pkuinfo`](https://github.com/pkuinfo) 下开源。

| 仓库 | 技术栈 | 简介 |
| --- | --- | --- |
| [`pku-harness`](https://github.com/pkuinfo/pku-harness) | Expo SDK 58、React Native 0.88、TypeScript、bun | **应用本体**：Agent 循环、设计系统、宿主服务、校园会话、调度器。优先支持 Android。 |
| [`pku-harness-plugins`](https://github.com/pkuinfo/pku-harness-plugins) | TypeScript、zod、bun workspace | SDK（`@pku-harness/sdk`）、所有内置插件（`@pku-harness/plugins`）、插件市场清单（`@pku-harness/registry`）、云服务协议（`@pku-harness/cloud-protocol`）、远程插件模板和示例。**想写插件，从这里开始。** |
| [`pkucli`](https://github.com/pkuinfo/pkucli) | Rust workspace（reqwest、tokio、clap） | 访问北大各类网站的命令行工具，也是应用对接的每个服务的**协议参考**。同时提供 Agent 技能（skills）。 |
| [`pkubdcard`](https://github.com/pkuinfo/pkubdcard) | Go（Gin）+ Preact | 分享校园卡付款码的网页应用，是 pkucli 校园卡流程更早的一个移植版。云服务 `card-share` 的界面和限流设计都参考了它。 |
| [`pkuharness-website`](https://github.com/pkuinfo/pkuharness-website) | Next.js 16 + Fumadocs 16、bun | 本网站：首页、下载、这份文档和插件市场。 |

## 仓库之间的关系 [#how-they-fit-together]

```
                 PKU IAAA (iaaa.pku.edu.cn)
                           │
      pkucli (Rust) ───────┼──────── protocol reference ────────┐
                           │                                     ▼
                     pku-harness (app) ◄── git submodule ── pku-harness-plugins
                     harness + host services               sdk · plugins · registry · cloud-protocol · cloud-server
                           │                                     │
                           ├── remote plugins (MCP, anyone) ◄────┤ templates/remote-plugin
                           │                                     │
                           └── PKU Harness Cloud provider ◄──────┘ cloud-protocol + cloud-server (reference)

   pkuharness-website: docs · marketplace (registry.json + indexed repos) · downloads (GitHub releases)
```

## pku-harness-plugins 的目录结构 [#inside-pku-harness-plugins]

| 目录 | 内容 |
| --- | --- |
| `packages/sdk` | `@pku-harness/sdk`：插件接口约定、纯函数工具和插件语言（`src/lang`：schema、解释器、宿主能力、加载器） |
| `packages/cloud-protocol` | `@pku-harness/cloud-protocol`：云服务线上协议的 schema、信封加密、分享链接 |
| `packages/cloud-server` | PKU Harness Cloud（云服务）的参考服务器实现（Bun + Hono + SQLite） |
| `plugins/<id>/PLUGIN.md` | 官方插件文档。随应用一起打包（`bun run bundle`），之后从各自的链接更新 |
| `plugins/<id>/src` | 用 TypeScript 写的内置插件（见 `plugins/index.ts` 里的 `builtinPlugins`） |
| `plugins/shared` | 内置插件之间共用的代码 |
| `scripts` | `plugin.ts`（作者命令行：`bun run plugin validate\|test\|run`）、`bundle-docs.ts`、`validate-registry.ts` |
| `registry` | 插件市场的 schema 和 `registry.json` |
| `templates/remote-plugin`、`examples/*` | 远程插件模板，以及 `demo-canteen` 和 `mock-llm` 两个示例 |

这些都是私有的 workspace 包，不会发布到 npm。应用把这个仓库作为 git 子模块 `plugins/` 引入。插件文档的分享方式和技能（skills）一样：一个文件夹或一个链接，由应用解释执行。详见[声明式插件](/docs/build/declarative-plugins)。

## 目前的内置插件 [#bundled-plugins-today]

插件文档：`classrooms`、`campus-events`、`grades`、`canteen`、`shuttle`、`notices`。

TypeScript 插件：`ui`（生成式界面）、`dashboard`、`scheduler`、`todo`、`schedule`、`timetable`、`course-sync`、`authenticator`（手机令牌）、`calendar`（校历）、`wallet`（校园卡、网费、宿舍水电）、`card-share`（通过云服务分享付款码）、`courses`（教学网）、`course-catalog`、`treehole`、`elective`、`finance`、`library`、`room-booking`、`memory`、`plugins`（插件管理和 AI 编写插件）、`deepseek`、`openai-compatible`。

每个插件的介绍见[插件市场](/marketplace)。
