本页整理自 [`pku-harness`](https://github.com/pkuinfo/pku-harness) 仓库里的开发计划和设计文档：`docs/PLAN.md`、`docs/CLOUD.md`、`docs/PLUGIN-LANGUAGE.md`、`docs/CLOUD-FUNCTIONS.md` 和 `docs/OTA.md`，内容截至 2026-10-24。各项工作以 PLAN.md 为准，它会随开发进度更新；需要最新细节时请直接查看它。

## 当前状态 [#current-status]

- Android 应用的 1.0.0 版本已经发布。
- OTA（over-the-air，空中下载）更新已经上线。App 的 JavaScript 代码（包括内置在 App 里的插件）有改动时，可以通过 OTA 直接更新到已安装的应用上，不需要重新安装 APK。插件文档不走 OTA，而是从各自的链接更新。
- PKU Harness Cloud（云服务）的官方实例还没有部署。
- 官方服务器上的插件服务端函数处于关闭状态。

## 已完成 [#done]

**基础与设计系统**：Expo + bun 项目脚手架、设计 token、玻璃质感的设计语言、动效基础组件、四个标签页的框架，以及首次启动引导。

**核心运行时**：数据存放在 SQLite 和系统密钥库中。插件运行时负责处理效果、授权和审批。模型服务以插件形式提供，默认使用 DeepSeek，也可以接入兼容 OpenAI 接口的服务。Agent 循环支持流式的工具调用。

**Agent 框架**：这是应用中负责和 AI 助手对话的部分，目前支持：
- 多个会话，自动生成标题，回复可以在后台继续；
- 斜杠命令；
- 输入框支持附件、消息排队和模型选择；
- 上下文管理与压缩；
- 提示词的排列方式便于模型服务复用前缀缓存；
- 显示 token 用量和费用的看板；
- 带审批的记忆功能：从不可信内容里得到的信息会先被「污染闸门」拦下，等你同意后才写入记忆。

**生成式界面**：json-render 组件目录、`ui.render` 工具，以及能把填写结果回传给助手的表单。

**校园服务接入**：原生的校园 HTTP 模块。通过 IAAA（北大统一身份认证）登录，只在服务要求时才需要二次验证。手机令牌。短信验证码一键读取。带文件选择器的 multipart 上传。在浏览器中以已登录状态打开校园网站。校园卡、ITS、树洞、教学网、bdkj、cwfw、cwpay、选课和图书馆的适配器。

**校园插件**：校园钱包（校园卡、网费、宿舍水电）、课表同步、教学网课程、成绩、树洞、校园活动、选课（只读）、财务、空间预约、课程查询、校历、食堂、班车、通知公告等。

**看板**：小组件模型，小组件可以由 AI 生成，也可以由插件提供。每个小组件在后台刷新时先显示上一次的数值（stale-while-revalidate）。看板还有编辑模式和小组件库。

**调度器**：重复规则引擎和准点通知。在 Android 上，检查任务在后台、甚至应用被杀掉之后都能准时运行。还包括由助手执行的定时任务、无人值守运行的策略，以及引导你授予准点送达所需权限的步骤。

**日程标签页**：支持单双周和课前提醒的课表、待办事项，以及可以自由设置重复规则的提醒。

**插件生态**：插件仓库，包括 SDK、插件清单及其校验器。通过 MCP（Model Context Protocol，模型上下文协议）连接的远程插件，调用时需要审批。应用内的插件市场。插件可以向应用添加页面、设置项、标签页、小组件和命令。

**插件语言（规范 1）**：插件可以是一个可分享的文件夹，里面有一个 `PLUGIN.md` 文件，由应用解释执行。这部分工作包括：
- SDK 中的解释器和宿主能力，包括 `verify.treehole`；
- 作者命令行（`bun run plugin validate|test|run`），每份文档录制好的测试都在持续集成（CI）中运行；
- 通过链接或 `pkuharness://plugin` 安装，安装前会显示审核页；
- 每天检查更新，如果新版本申请了更多权限，要等你同意后才会更新；支持回滚；
- 官方文档随应用打包，并从各自的链接更新；
- [AI 编写插件](/docs/build/ai-authoring)用到的工具（`plugins.reference / validate / tryTool / source / install`）。

**官方插件文档**：classrooms、campus-events、grades、canteen、shuttle 和 notices 已经从 TypeScript 移植成插件文档。每个移植版本都通过了对拍测试，原来的 TypeScript 版本已经删除。

**PKU Harness Cloud（云服务）**：通信协议 v1 和信封加密、SDK 中的云服务类型，以及插件清单的 `cloud` 字段。用 Bun、Hono 和 SQLite 实现的参考服务器。宿主客户端，包括设备身份、授权、端到端加密的存储和通道，以及「设置 → 云服务」页面。Android 前台服务（`services.ongoing`）。`card-share` 插件，带网页查看页和 `pkuharness://share` 链接。

**发布与更新**：1.0.0 版本已经发布。推送版本 tag 后，CI 会构建签名的 APK，并发布到 GitHub Releases。自建、经过代码签名的 OTA 更新已经上线：它使用 expo-updates，在 CI 中基于公开的提交签名，由我们的服务器以静态文件的形式提供。

## 进行中 [#in-progress]

- **把集成移植成插件文档**：接下来是课程查询、选课、图书馆的只读功能和树洞工具，之后是需要新宿主能力的那一批。详见[声明式插件](/docs/build/declarative-plugins)。
- **iOS**：应用已经能在 iOS 上安全启动，钥匙串和通知相关的工作也已完成。校园 HTTP 模块的 Swift 移植还没有做。
- **第二批插件**：更完整的水电和财务功能，教学网作业提交和智云课堂，图书馆的借阅、续借和座位预约，以及门户应用等校园生活功能。
- **实地验证**：有些服务只能在特定时间测试。例如选课系统，不在补退选期间就无法测试。

## 计划中 [#planned]

- **PKU Harness Cloud**：部署官方实例，并保持最小规模，只提供实时分享用的中继、小型的端到端加密存储和查看页。支持多台设备配对。
- **插件需要的宿主能力**：为插件提供限定范围的公网 HTTP 访问。
- **限定范围的会话授权**：让远程插件不接触你的账号密码，也能操作校园服务。
- **官方托管的模型服务选项。**

## 暂缓 [#on-hold]

**插件服务端函数**目前暂缓开发。这类函数在 `PLUGIN.md` 里用 `server:` 声明（见 `docs/CLOUD-FUNCTIONS.md`）。已有的实现保留在参考服务器中，但在官方服务器上是关闭的；集合、定时任务、推送、群组和 webhook 都暂不开发。现阶段请让插件在手机上完成工作，或者使用你自己的后端。

## 暂不考虑 [#not-planned-for-now]

暂不考虑开发应用的网页版，也不考虑在应用内支付：需要付款时，应用会跳转到官方收银台。
