## 已完成 [#done]

| 方向 | 要点 |
| --- | --- |
| 基础与设计系统 | Expo + bun 脚手架、设计 token、玻璃质感设计语言、动效基础组件、四个标签页的框架、首次启动引导 |
| 核心运行时 | SQLite + 系统密钥库存储，插件运行时（效果、授权、审批），模型服务插件（默认 DeepSeek，另有 OpenAI 兼容），支持流式工具调用的 Agent 循环 |
| Agent 框架 | 多会话（自动标题、后台回复）、斜杠命令、输入框（附件、排队、模型选择）、上下文管理与压缩、对前缀缓存友好的提示词、用量与费用看板、带污染闸门和审批的记忆 |
| 生成式界面 | json-render 组件目录、`ui.render`、可以把提交结果回传给助手的表单 |
| 校园服务接入 | 原生校园 HTTP 模块，IAAA 登录（按需二次验证），手机令牌，短信验证码一键读取，带文件选择器的 multipart 上传，在浏览器中免登录打开校园网站，校园卡、ITS、树洞、教学网、bdkj、cwfw、cwpay、选课、图书馆的适配器 |
| 校园插件 | 校园钱包（校园卡、网费、宿舍水电）、课表同步、教学网课程、成绩、树洞、校园活动、选课（只读）、财务、空间预约、课程查询、校历、食堂、班车、通知公告…… |
| 看板 | 小组件模型、AI 生成的小组件和插件小组件、stale-while-revalidate 实时数据、编辑模式、小组件库 |
| 调度器 | 重复规则引擎、准点通知；Android 上后台以及应用被杀后都能准点执行检查；助手驱动的定时任务、无人值守运行策略、送达权限引导 |
| 日程标签页 | 支持单双周和课前提醒的课表、待办、可自由设置重复规则的提醒 |
| 插件生态 | 插件仓库（SDK、插件清单和校验器）、带审批的远程 MCP 插件、应用内插件市场、插件界面扩展（页面、设置项、标签页、小组件、命令） |
| 插件语言（规范 1） | 插件是可分享的 `PLUGIN.md` 文件夹，由应用解释执行：SDK 解释器、宿主能力（包括 `verify.treehole`）、作者命令行（`bun run plugin validate\|test\|run`），每份文档的录制测试都在 CI 里跑；可以通过链接或 `pkuharness://plugin` 安装，安装前有审核页；每日自动更新（申请更多权限的更新要等用户同意），支持回滚；官方文档随应用打包，并从各自的链接更新；[AI 编写插件](/docs/build/ai-authoring)的工具（`plugins.reference / validate / tryTool / source / install`） |
| 官方插件文档 | classrooms、campus-events、grades、canteen、shuttle、notices 已从 TypeScript 移植过来（对拍测试通过，已删除 TypeScript 版本） |
| PKU Harness Cloud（云服务） | 线上协议 v1 和信封加密、SDK 云服务类型、插件清单的 `cloud` 字段、参考服务器（Bun + Hono + SQLite）、宿主客户端（设备身份、授权、端到端加密的存储和通道、设置 → 云服务）、Android 前台服务（`services.ongoing`）、带网页查看页和 `pkuharness://share` 链接的 `card-share` |
| 发布与更新 | 已发布 v1.0.0：打版本 tag 后由 CI 构建签名 APK 并发布到 GitHub Releases。自建、代码签名的 OTA 更新已上线（expo-updates，在 CI 中基于公开提交签名，我们的服务器只托管静态文件） |

## 进行中 [#in-progress]

- **把集成移植成插件文档**：接下来是课程查询、选课、图书馆的只读功能和树洞工具，然后是需要新宿主能力的那一批。详见[声明式插件](/docs/build/declarative-plugins)。
- **iOS**：已经能安全启动，钥匙串和通知相关的工作已完成，校园 HTTP 模块的 Swift 移植还没做。
- **第二批插件**：更完整的水电和财务功能，教学网作业提交和智云课堂，图书馆（借阅、续借、座位），校园生活（门户应用等）。
- **实地验证**：有些服务只能在特定时间测试（比如选课，不在补退选期间就测不了）。

## 计划中 [#planned]

- **PKU Harness Cloud**：部署官方实例，并保持最小化（实时分享用的中继、小型端到端加密存储和查看页）；多设备配对。
- **插件需要的宿主能力**：面向插件、限定范围的公网 HTTP。
- **限定范围的会话授权**：让远程插件不接触账号密码也能操作校园服务。
- 官方托管的模型服务选项。

## 暂缓 [#on-hold]

- **插件服务端函数**（`PLUGIN.md` 里的 `server:`，见 `docs/CLOUD-FUNCTIONS.md`）：已有的实现保留在参考服务器里，但官方服务器上是关闭的；集合、定时任务、推送、群组和 webhook 都不再开发。插件请尽量在手机上完成工作，或者使用你自己的后端。

## 暂不考虑 [#not-planned-for-now]

应用的网页版，以及应用内支付（支付会跳转到官方收银台）。
