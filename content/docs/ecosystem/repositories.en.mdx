Everything is open source under the [`pkuinfo`](https://github.com/pkuinfo) GitHub organisation.

| Repository | Stack | What it is |
| --- | --- | --- |
| [`pku-harness`](https://github.com/pkuinfo/pku-harness) | Expo SDK 58, React Native 0.88, TypeScript, bun | **The app**: the harness (agent loop, design system, host services, campus sessions, scheduler). Android first. |
| [`pku-harness-plugins`](https://github.com/pkuinfo/pku-harness-plugins) | TypeScript, zod, bun workspace | The SDK (`@pku-harness/sdk`), every bundled plugin (`@pku-harness/plugins`), the marketplace registry (`@pku-harness/registry`), the cloud protocol (`@pku-harness/cloud-protocol`), the remote plugin template and examples. **Start here to build a plugin.** |
| [`pkucli`](https://github.com/pkuinfo/pkucli) | Rust workspace (reqwest, tokio, clap) | Command-line tools for PKU web services and the **protocol reference** for every service the app talks to. Also ships agent skills. |
| [`pkubdcard`](https://github.com/pkuinfo/pkubdcard) | Go (Gin) + Preact | A web app to share a campus-card payment code; an earlier port of pkucli's campus-card flow. Its UI and rate limits inspired the cloud `card-share` design. |
| [`pkuharness-website`](https://github.com/pkuinfo/pkuharness-website) | Next.js + Fumadocs, bun | This website: landing page, downloads, these docs, the marketplace. |

## How they fit together

```
                 PKU IAAA (iaaa.pku.edu.cn)
                           │
      pkucli (Rust) ───────┼──────── protocol reference ────────┐
                           │                                     ▼
                     pku-harness (app) ◄── git submodule ── pku-harness-plugins
                     harness + host services               sdk · plugins · registry · cloud-protocol · cloud-server
                           │                                     │
                           ├── remote plugins (MCP, anyone) ◄────┤ templates/remote-plugin
                           │                                     │
                           └── PKU Harness Cloud provider ◄──────┘ cloud-protocol + cloud-server (reference)

             pkuharness-website: docs · marketplace (reads registry.json) · downloads (GitHub releases)
```

## Inside pku-harness-plugins

| Folder | Contents |
| --- | --- |
| `packages/sdk` | `@pku-harness/sdk`: plugin contract, pure helpers and the plugin language (`src/lang`: schemas, interpreter, abilities, loader) |
| `packages/cloud-protocol` | `@pku-harness/cloud-protocol`: Cloud wire schemas, envelope crypto, share links |
| `packages/cloud-server` | Reference PKU Harness Cloud server (Bun + Hono + SQLite) |
| `plugins/<id>/PLUGIN.md` | Official plugin documents, bundled with the app (`bun run bundle`) and updated from their link |
| `plugins/<id>/src` | Bundled TypeScript plugins (`builtinPlugins` in `plugins/index.ts`) |
| `scripts` | `plugin.ts` (author CLI: `bun run plugin validate\|test\|run`), `bundle-docs.ts`, `validate-registry.ts` |
| `plugins/shared` | Code shared by bundled plugins |
| `registry` | Marketplace schema + `registry.json` |
| `templates/remote-plugin`, `examples/*` | Remote plugin template, demo-canteen, mock-llm |

These are private workspace packages: nothing is published to npm. The app includes the repository
as its git submodule `plugins/`. Plugin documents are shared like skills, as a folder or link the
app interprets; see [Declarative plugins](/docs/build/declarative-plugins).

## Bundled plugins today

Plugin documents: `classrooms`, `campus-events`, `grades`, `canteen`, `shuttle`.

TypeScript: `ui` (generative UI), `dashboard`, `scheduler`, `todo`, `schedule`, `timetable`,
`course-sync`, `authenticator` (手机令牌), `calendar` (校历), `wallet` (campus card, network fee,
utilities), `card-share` (share a payment code through the Cloud), `courses` (Blackboard),
`course-catalog`, `treehole`, `elective`, `finance`, `library`, `room-booking`, `notices` (being
ported to a document), `memory`, `plugins` (plugin management and AI authoring), `deepseek`,
`openai-compatible`. See the [marketplace](/marketplace)
for descriptions.
