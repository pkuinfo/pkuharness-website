Everything is open source under the [`pkuinfo`](https://github.com/pkuinfo) GitHub organisation.

| Repository | Stack | What it is |
| --- | --- | --- |
| [`pku-harness`](https://github.com/pkuinfo/pku-harness) | Expo SDK 58, React Native 0.88, TypeScript, bun | **The app**: the harness itself (agent loop, design system, host services, campus sessions, scheduler). Android first. |
| [`pku-harness-plugins`](https://github.com/pkuinfo/pku-harness-plugins) | TypeScript, zod, bun workspace | The SDK (`@pku-harness/sdk`), every bundled plugin (`@pku-harness/plugins`), the marketplace registry (`@pku-harness/registry`), the cloud protocol (`@pku-harness/cloud-protocol`), the remote plugin template and examples. **Start here to build a plugin.** |
| [`pkucli`](https://github.com/pkuinfo/pkucli) | Rust workspace (reqwest, tokio, clap) | Command-line tools for PKU web services, and the **protocol reference** for every service the app talks to. Also ships agent skills. |
| [`pkubdcard`](https://github.com/pkuinfo/pkubdcard) | Go (Gin) + Preact | A web app for sharing a campus-card payment code, and an earlier port of pkucli's campus-card flow. Its UI and rate limits shaped the cloud `card-share` design. |
| [`pkuharness-website`](https://github.com/pkuinfo/pkuharness-website) | Next.js 16 + Fumadocs 16, bun | This website: landing page, downloads, these docs and the marketplace. |

## How they fit together

```
                 PKU IAAA (iaaa.pku.edu.cn)
                           │
      pkucli (Rust) ───────┼──────── protocol reference ────────┐
                           │                                     ▼
                     pku-harness (app) ◄── git submodule ── pku-harness-plugins
                     harness + host services               sdk · plugins · registry · cloud-protocol · cloud-server
                           │                                     │
                           ├── remote plugins (MCP, anyone) ◄────┤ templates/remote-plugin
                           │                                     │
                           └── PKU Harness Cloud provider ◄──────┘ cloud-protocol + cloud-server (reference)

   pkuharness-website: docs · marketplace (registry.json + indexed repos) · downloads (GitHub releases)
```

## Inside pku-harness-plugins

| Folder | Contents |
| --- | --- |
| `packages/sdk` | `@pku-harness/sdk`: the plugin contract, pure helpers and the plugin language (`src/lang`: schemas, interpreter, abilities, loader) |
| `packages/cloud-protocol` | `@pku-harness/cloud-protocol`: Cloud wire schemas, envelope crypto, share links |
| `packages/cloud-server` | The reference PKU Harness Cloud server (Bun + Hono + SQLite) |
| `plugins/<id>/PLUGIN.md` | Official plugin documents. They ship with the app (`bun run bundle`) and update from their link |
| `plugins/<id>/src` | Bundled TypeScript plugins (`builtinPlugins` in `plugins/index.ts`) |
| `plugins/shared` | Code shared by bundled plugins |
| `scripts` | `plugin.ts` (author CLI: `bun run plugin validate\|test\|run`), `bundle-docs.ts`, `validate-registry.ts` |
| `registry` | Marketplace schema and `registry.json` |
| `templates/remote-plugin`, `examples/*` | The remote plugin template, plus `demo-canteen` and `mock-llm` |

These are private workspace packages; nothing goes to npm. The app pulls the repository in as its
git submodule `plugins/`. Plugin documents are shared the way skills are, as a folder or a link the
app interprets. See [Declarative plugins](/en/docs/build/declarative-plugins).

## Bundled plugins today

Plugin documents: `classrooms`, `campus-events`, `grades`, `canteen`, `shuttle`, `notices`.

TypeScript: `ui` (generative UI), `dashboard`, `scheduler`, `todo`, `schedule`, `timetable`,
`course-sync`, `authenticator` (手机令牌), `calendar` (校历), `wallet` (campus card, network fee,
utilities), `card-share` (share a payment code through the Cloud), `courses` (Blackboard),
`course-catalog`, `treehole`, `elective`, `finance`, `library`, `room-booking`, `memory`, `plugins`
(plugin management and AI authoring), `deepseek`, `openai-compatible`.

The [marketplace](/en/marketplace) has a description of each.
