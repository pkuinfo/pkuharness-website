PKU Harness is the one app a PKU student installs. You sign in once with your campus account
(IAAA) and reach every campus system from there: timetable, campus card, network fee, Treehole
(树洞), Blackboard (教学网), finance, room booking, and whatever plugins add. An AI agent sits at
the core and works those systems for you, and every feature it can use is also one tap away in
native UI.

## Everything is a plugin

The app itself is only a **harness**: an agent loop, a design system and a set of host services.
Everything else is a **plugin**: each campus service, the dashboard, reminders, even the model
provider. Plugins are all equal. One that ships inside the app and one that a student runs on
their own server use the same contract, sit in the same plugin list and follow the same
permissions.

```
 ┌──────────────── PKU Harness app (the harness) ────────────────┐
 │  Agent loop      Design system (HostUI)     Host services      │
 │      │                  │                 (campus, scheduler,  │
 │      └────── tools ─────┴───── screens ──  widgets, todos, …)  │
 └──────────▲──────────────────────▲──────────────────▲───────────┘
            │                      │                  │
   bundled plugins          remote plugins       PKU Harness Cloud
   (TypeScript, SDK)        (MCP over HTTPS)     (optional backend)
```

Two rules follow, and the rest of these docs keep coming back to them:

- **Human and AI are equal operators.** Every capability is one typed tool. A screen calls it when
  you tap; the agent calls it in a conversation. Anything you can do, the agent can do, and the
  other way round.
- **Credentials never leave the device.** The harness signs in to campus services itself and hands
  plugins responses. Plugins never see passwords or session tokens.

## Feeding these docs to an agent

Every page is also served as Markdown, so you can hand an agent exactly the context it needs.
The docs come in Simplified Chinese (default, under `/docs`) and English (under `/en/docs`).

| URL | Content |
| --- | --- |
| [`/llms.txt`](/llms.txt) | Index of every page in both languages, with one-line descriptions |
| [`/llms-full.txt`](/llms-full.txt) | Every English page in one file |
| [`/llms-full.zh.txt`](/llms-full.zh.txt) | Every Chinese page in one file |
| `/en/docs/<page>.md` | One English page, e.g. [`/en/docs/sdk/plugin.md`](/en/docs/sdk/plugin.md) |
| `/docs/<page>.md` | The same page in Chinese |
| `/en/docs/<page>` with `Accept: text/markdown` | Same as `.md` (content negotiation) |

Under each page title there are **Copy Markdown** and **Open in…** buttons. In the Markdown
version, the Cloud API reference pages render their operations and schemas as text.

```bash
# Give Claude Code the plugin checklist and the SDK contract
curl -s https://<this-site>/en/docs/for-agents.md https://<this-site>/en/docs/sdk/plugin.md > plugin-context.md
```
